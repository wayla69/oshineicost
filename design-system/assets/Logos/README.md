# Logos

- `oshinei-roundel.svg` — The deck and report roundel: a `navy` (#1f3a6b) disc, white hairline ring, OSHINEI (Prompt 800) over おしねい, and a rising white sparkline. Full colour; use on white or `bg-page`. Its text is live SVG text in Prompt, so inline it where the font is loaded or it falls back to a system sans.
- The app's own mark (お on an indigo → violet tile) is CSS, not a file: see the LogoMark component.
