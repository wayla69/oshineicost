# Pill

A tag: one or two words of direction or status, 10.5px/600 on a tint with a 1px edge and a 3px corner. Not a rounded pill.

- `.pill` + `.pill-up`, `.pill-down`, `.pill-neu`, `.pill-warn` or `.pill-danger`.
- Deltas carry an arrow and sign ("▲ 12.4%"), so direction never rests on colour alone.
