# SubtabBar

Switches views inside one page: underline tabs on a 1px rule; the active tab takes the page group's `-ink` text and a 2px underline in its `group-*` hue (`accent` on a page outside a group).

- `.subtab-bar` > `.subtab-btn` (+ `.active`). Leave 20px below the bar.
- On phones the tabs wrap to extra rows rather than scrolling the page sideways.
