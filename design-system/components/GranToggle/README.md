# GranToggle

The segmented control for time granularity and small view switches (วัน / สัปดาห์ / เดือน): joined segments in a `border-control` frame; the selected one is filled `accent`.

- `.gran-track` > `.gran-btn`; the selected one gets `.gran-active`.
- Changing it re-runs the page's queries; keep it beside the chart or table it drives.
