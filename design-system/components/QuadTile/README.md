# QuadTile

The four menu-engineering quadrants as clickable filter tiles: Star, Plowhorse, Puzzle, Dog. Each has a light and a dark ink (`quad-*-ink`) that reads on its tint in both themes.

- `.quad-tile` + `.quad-star|quad-plow|quad-puzzle|quad-dog`, holding `.qname`, `.qcount`, `.qdesc`. `.active` draws a 2px edge in the tile's own colour.
- Always all four, in that order. Buffet (B) and à-la-carte (A) SKUs are analysed separately.
