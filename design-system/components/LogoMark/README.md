# LogoMark

The app mark: お in white Prompt 800 on a 36px tile, 10px radius, filled indigo → violet at 135° with an indigo glow.

- `.logo-mark` with the single character お. Use it only in the sidebar, the UI-kit hero (52px) and app icons.
- On decks and printed reports use the navy roundel from `assets/Logos/` instead.
