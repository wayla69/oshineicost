# Sidebar

The navy navigation rail: the logo block, uppercase group headings, stroke-icon items, and a 3px white marker at the rail's edge on the active item.

- `.sidebar` > `.sidebar-logo` (LogoMark + name) and `.sidebar-nav` with `.nav-section` headings and `.nav-item` rows (`svg.nav-icon` + `.nav-label`). `.active` marks the current page.
- Labels are words only; the stroke icon is the only pictogram. No emoji in labels or headings.
- Text on the rail: `nav-ink` at rest (7.3:1), `nav-active-ink` hovered or active, `nav-section-ink` (5.6:1) for headings.
