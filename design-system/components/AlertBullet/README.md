# AlertBullet

A list of findings: each row is an outlined status tag (ดี / ต้องแก้ / เฝ้าดู / ข้อมูล) and one sentence, separated by hairlines.

- `.alert-bullet.good|bad|warn|info` > `.tag` + the sentence. The tag carries the word, so status never rests on colour.
- Write the finding and the baht at stake in one sentence; bold the number. No emoji.
