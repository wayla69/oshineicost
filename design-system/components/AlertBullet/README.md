# AlertBullet

A one-line finding with an icon, coloured by meaning through a 3px left rule and a 6% tint.

- `.alert-bullet` + `.good`, `.bad`, `.warn` or `.info`; children `.ico` and the text. The dive-in panel uses the same pattern as `.dive-bullet`.
- Write the finding and the baht at stake in one sentence; bold the number.
