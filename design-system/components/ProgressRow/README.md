# ProgressRow

Branch progress toward a target: name, an 8px flat bar, and the figure, in a 130px / flexible / 110px grid.

- `.progress-row` > `.pname`, `.progress-track` > `.progress-fill.on|near|off` (width = % of target), `.progress-meta`.
- `.ontrack-dot.on|near|off` can lead the name. Targets are the branch's own figure for the same month last year.
