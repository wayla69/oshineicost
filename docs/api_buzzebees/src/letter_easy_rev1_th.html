เรื่องสอบถามการตั้งค่าคูปองภายนอก ใบเสร็จรับเงิน และรอบการส่งข้อมูลของสาขา สำหรับระบบสมาชิก Buzzebees CRM PLUS
เรียนฝ่ายดูแลลูกค้า และทีมเทคนิค Easy POS
อ้างถึงหนังสือ Oshinei เลขที่ OSH-CRM-2026-003 ลงวันที่ 27 ตุลาคม 2569 เรื่อง สอบถามความสามารถของตัวเชื่อม HO_CRM

ตามที่ Oshinei ได้สอบถามเรื่องตัวเชื่อม HO_CRM ตามหนังสือที่อ้างถึงนั้น Oshinei ได้เลือกรูปแบบการเชื่อมต่อระบบสมาชิก Buzzebees CRM PLUS ที่ไม่ต้องพัฒนาระบบ Easy POS เพิ่มเติม โดย Oshinei จะอ่านข้อมูลการขายจากฐานข้อมูล HQ_Oshinei ด้วยบัญชีอ่านอย่างเดียวที่ใช้อยู่ในปัจจุบัน และส่งต่อให้ Buzzebees ผ่าน API ของ Oshinei เอง จึงขอยกเลิกคำถามตามหนังสือฉบับก่อน และ Easy POS ไม่ต้องสร้าง view บัญชีผู้ใช้ หรือเปิดการเชื่อมต่อเครือข่ายเพิ่มเติม

ในรูปแบบนี้ สมาชิกจะใช้คูปองของ Buzzebees ที่หน้าร้านผ่านฟังก์ชันคูปองภายนอก (external coupon) ที่มีอยู่ใน Easy POS แล้ว Oshinei จึงขอสอบถามข้อมูล 3 ข้อ ดังนี้

1. ชุดคูปองภายนอกสำหรับรหัสคูปองของ Buzzebees

ขอให้ตั้งชุดคูปอง (coupon series) สำหรับรหัสคูปองของ Buzzebees และขอทราบรายละเอียด ดังนี้

  • รหัสคูปองที่ระบบรับได้มีรูปแบบและความยาวเท่าใด
  • ต้องบันทึกรหัสคูปองเข้าระบบล่วงหน้าก่อนใช้หรือไม่ หากต้องบันทึก สามารถนำเข้าเป็นชุดจากไฟล์ได้หรือไม่ และใช้รูปแบบไฟล์ใด
  • การตั้งค่า IsUniqueCouponNumber ป้องกันการใช้รหัสเดียวกันซ้ำที่หน้าร้านได้หรือไม่

2. ใบเสร็จรับเงิน

ใบเสร็จรับเงินพิมพ์ชื่อสาขาและเลขที่บิล (SaleNum) ชัดเจนในทุกสาขาหรือไม่ และฟังก์ชัน QR บนใบเสร็จ (QrDataReceipt) ซึ่งกำหนดไว้แล้ว 35 สาขาแต่ยังไม่เปิดใช้งาน สามารถเปิดใช้ได้หรือไม่

3. รอบการส่งข้อมูลของสาขาเข้าสำนักงานใหญ่

แต่ละสาขาส่งข้อมูลการขายเข้าฐานข้อมูล HQ_Oshinei ทุกกี่นาที และสามารถปรับให้ส่งทุก 15 นาทีได้หรือไม่ เนื่องจากสมาชิกจะได้รับคะแนนหลังจากข้อมูลบิลเข้าถึงสำนักงานใหญ่แล้วเท่านั้น

นอกจากนี้ ขอสอบถามเพิ่มเติมว่า หน้าจอแคชเชียร์สามารถบันทึกหมายเลขโทรศัพท์ของสมาชิกลงในช่อง CustRefNum ได้โดยไม่ต้องพัฒนาเพิ่มหรือไม่ ข้อนี้ใช้ประกอบการพิจารณาในระยะถัดไป
