เรื่องสอบถามความสามารถของตัวเชื่อม HO_CRM สำหรับการเชื่อมต่อระบบสมาชิก Buzzebees CRM PLUS
เรียนฝ่ายดูแลลูกค้า และทีมเทคนิค Easy POS
อ้างถึงข้อกำหนด API CRM PLUS ของ Buzzebees (API CRM PLUS_full – 2026)

ด้วย Oshinei มีแผนเปิดใช้ระบบสมาชิกและสะสมคะแนนของ Buzzebees (CRM PLUS ผ่าน LINE Official Account) ในทุกสาขาที่ใช้ระบบ Easy POS (ปัจจุบัน 33 สาขา) โดย Buzzebees ได้เสนอ API มาตรฐานที่ระบบ POS จะต้องเรียกใช้ขณะชำระเงิน ได้แก่ การค้นหาสมาชิก การสะสมคะแนน การตรวจสอบและใช้สิทธิ์คูปอง และการยกเลิกคะแนน

จากการตรวจสอบฐานข้อมูล HQ_Oshinei พบว่าระบบ Easy POS มีโครงสร้างรองรับการเชื่อมต่อระบบ CRM ภายนอกอยู่แล้ว แต่ยังไม่เคยมีการใช้งาน ได้แก่

  • ตัวเชื่อม HO_CRM ในตาราง ThirdParty (สถานะเปิดใช้งาน)
  • ตาราง PromotionByCRM และ CallAPILog
  • ช่อง EarnPoint, RedeemedPoint และ BalancePoint ในตาราง Sale
  • ช่อง IsSucceedSendHOCRM ในตาราง SaleSync
  • ช่อง IsCRMCoupon ในตาราง CouponSeries

Oshinei จึงขอสอบถามข้อมูล 3 ข้อ เพื่อประกอบการพิจารณาเลือกรูปแบบการเชื่อมต่อ ดังนี้

1. การเชื่อมต่อกับ Buzzebees ผ่าน HO_CRM

ตัวเชื่อม HO_CRM สามารถเชื่อมต่อกับ API ของ Buzzebees ได้ด้วยการตั้งค่าเท่านั้น หรือจะต้องพัฒนาเพิ่มเติม และ Easy POS เคยเชื่อมต่อ HO_CRM กับ Buzzebees หรือผู้ให้บริการ CRM รายอื่นมาก่อนหรือไม่ หากเคย ขอทราบชื่อผู้ให้บริการและรูปแบบการเชื่อมต่อที่ใช้

2. หน้าจอสมาชิกและคะแนนบนเครื่อง POS

ระบบ POS มีหน้าจอให้พนักงานแคชเชียร์สแกน QR สมาชิกหรือระบุหมายเลขโทรศัพท์ แสดงคะแนนคงเหลือและคูปองที่ใช้ได้ บันทึกการใช้คูปอง และพิมพ์คะแนนที่ได้รับบนใบเสร็จรับเงินอยู่แล้วหรือไม่ และในกรณีที่ระบบสมาชิกไม่ตอบกลับ ระบบ POS ยังสามารถปิดรายการขายได้ตามปกติ และส่งข้อมูลซ้ำภายหลังได้หรือไม่

3. ระยะเวลาและค่าใช้จ่าย

หากจำเป็นต้องพัฒนาเพิ่มเติม ขอทราบขอบเขตงาน ระยะเวลาดำเนินการ และค่าใช้จ่ายโดยประมาณ ทั้งในส่วนการพัฒนาและการติดตั้งในทุกสาขา

ทั้งนี้ Oshinei กำลังพิจารณาอีกทางเลือกหนึ่ง คือให้ Buzzebees อ่านข้อมูลการขายจากฐานข้อมูล HQ_Oshinei ผ่าน view แบบอ่านอย่างเดียว ซึ่งไม่ต้องแก้ไขระบบ POS คำตอบของ Easy POS จะใช้ประกอบการตัดสินใจระหว่างสองทางเลือกนี้
