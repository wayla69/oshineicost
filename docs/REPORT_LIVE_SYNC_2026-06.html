🔴 กฎเหล็ก (Standing Rule)

ต้นทุน/COGS ในทุกการคำนวณ ใช้ BoM ของเราเท่านั้น — ระบบ POS ไม่มีการบันทึกต้นทุนวัตถุดิบ (ตรวจสอบแล้ว: ต้นทุนใน POS = 0 ทุกรายการ) ดังนั้น margin / กำไร ทั้งหมดอ้างอิงสูตร BoM ของเรา ไม่นำต้นทุนจาก POS มาใช้

⚠️ ข้อจำกัด (ตามจริง)

  • POS ไม่มีต้นทุน/วัตถุดิบ → ทุก margin ใช้ BoM (ตามกฎเหล็ก) · stock variance ทำไม่ได้จาก POS
  • เวลาในครัวมีเฉพาะสาขาที่ใช้ KDS (2/27)
  • P&L ต่อบิล (COGS via BoM รายบิล) เป็นงานชิ้นถัดไป

➡️ ขั้นตอนถัดไป

  • สร้างหน้ารายงานบน Dashboard จากข้อมูลที่เตรียมไว้ (เริ่มจาก P&L ต่อบิล, Payment mix, Void)
  • เปลี่ยนรหัสผ่าน DB (security) และพิจารณาเปิดเวลาในครัว/ต้นทุนใน POS หากต้องการ margin จาก POS ในอนาคต
