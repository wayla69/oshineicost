3รับของและแจ้งของขาด/เสีย

ทุกครั้งที่ของมาถึง · ของเสียหายที่พบภายหลังให้แจ้งของขาด/เสีย

ตัดเบิกรายวัน → จำนวนที่ควรสั่งจากใบตัดเบิก (ครบ 14 วัน ก่อนนั้นกรอกเอง) → รับ / แจ้งของขาด → นับของ

  1. แตะ รับของ ที่แถบล่าง หัวข้อ “ใบสั่งซื้อที่คลังจัดส่งแล้ว” มีหลายใบ แตะ รับของ ที่ใบที่ของมาถึง
  2. ตอบคำถามเดียว รับครบตามที่คลังส่งทุกรายการ? ครบแตะ รับครบ
  3. ไม่ครบแตะ มีรายการไม่ครบ พิมพ์ชื่อวัตถุดิบ แตะ เลือก แก้ช่อง รับจริง และเลือกสาเหตุ รายการอื่นนับว่ารับครบ
  4. ปลาทั้งตัว: กรอกจำนวนตัวที่ได้รับเป็นจำนวนเต็มข้างน้ำหนัก ขนาดแพ็คไม่ตรงกับระบบ แตะ ขนาดแพ็คไม่ตรง
  5. ติ๊ก ตรวจสภาพและจำนวนครบแล้ว แล้วแตะ บันทึกรับของ และแตะ บันทึกรับของ ในคำถามที่ขึ้นมา
  6. พบของเสียหายภายหลัง: การ์ด แจ้งของขาด/เสีย → แจ้งของขาด/เสีย ที่ใบนั้น → เลือกรายการ ใส่จำนวนและสาเหตุ → ส่งแจ้งของขาด/เสีย แล้วส่งรูปถ่ายทางไลน์ถึงประสานงานขาย

ระบบไม่รับรูปถ่าย ส่งทางไลน์ถึงประสานงานขายเท่านั้น · รายการที่รับครบโดยไม่แจ้งในวันรับ อาจไม่ได้รับพิจารณา

บันทึกผิดใบ แตะ ยกเลิกใบรับของ ต้องระบุเหตุผลและประสานงานขายเห็นเหตุผลนั้น · ใบที่เกิดจากการอนุมัติเรื่องที่แจ้ง และใบในเดือนที่ปิดแล้ว ยกเลิกไม่ได้ · กรอกในไฟล์ Excel ก็ได้: ดาวน์โหลดแบบฟอร์ม → กรอก → นำเข้าไฟล์ (ปลาทั้งตัวกรอกในแอปเท่านั้น)

รับการแจ้งเตือนบนมือถือ: แตะ ฉัน แตะ เปิดการแจ้งเตือน ในการ์ด “แจ้งเตือนตอนเช้า”มีข้อสงสัย ติดต่อประสานงานขาย · คู่มือ: /docs/pilot/branch_guide.html
