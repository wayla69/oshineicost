4นับของสิ้นเดือน (นับครบทุกรายการ)

วันที่ 1 ของทุกเดือน นับครบทุกรายการก่อนรับของในวันนั้น · ปิดเดือนต้องนับ 100%

ตัดเบิกรายวัน → จำนวนที่ควรสั่งจากใบตัดเบิก (ครบ 14 วัน ก่อนนั้นกรอกเอง) → รับ / แจ้งของขาด → นับของ

  1. แตะ นับของสิ้นเดือน ที่หน้าแรก (หรือแตะแถวงานนับของใน ต้องทำวันนี้) หน้าจอบอกว่าครั้งนี้เป็นการนับครั้งแรกหรือนับสิ้นเดือน และนับครบทุกรายการ
  2. แตะโซนแล้วนับทีละโซน เครื่องหมาย ✓ ที่โซนคือนับครบทุกรายการของโซนนั้น (ใส่ 0 ถ้าไม่มีของ ช่องว่างถือว่ายังไม่ได้นับ)
  3. ใส่จำนวนที่นับจริงตามหน่วยในแถว ใช้ปุ่ม − / + หรือพิมพ์ รายการที่มาเป็นกล่องของแพ็คมี 2 ช่อง กล่อง และ แพ็ค ใส่เท่าที่นับได้ ระบบรวมให้
  4. ติ๊ก เฉพาะรายการที่ยังไม่ได้นับ เพื่อดูว่าเหลืออะไร ระบบบันทึกร่างให้เอง ส่งร่างค้างไว้ได้ แต่ยังไม่ใช่การปิดเดือน
  5. แตะ ส่งผลนับ ถ้ายังมีรายการที่ไม่ได้นับ ระบบแจ้ง “ยังไม่ได้นับ N รายการ ปิดเดือนต้องนับของครบทุกรายการ” พร้อมชื่อรายการแรก ๆ แตะ กลับไปนับ
  6. นับครบแล้วแตะ ส่งผลนับ ในคำถามที่ขึ้นมา · ไม่มีทางปิดเดือนด้วยการนับบางส่วน การนับเสริมรายสัปดาห์กลุ่มมูลค่าสูง (ถ้าเปิดใช้) เป็นการตรวจเสริมระหว่างเดือน ไม่ใช่การปิดเดือน

ส่งแล้วแก้ไม่ได้ ถ้าผิดให้นับใหม่ · ครั้งแรกเป็นการนับครั้งแรก ครั้งต่อไปเป็นการนับสิ้นเดือนและเป็นการนับครั้งแรกของเดือนถัดไปให้เอง · ปิดเดือนเดือนแล้วทำใหม่ไม่ได้

หลังส่งผลนับสิ้นเดือน ที่ปุ่ม ส่วนต่างการใช้ ในหน้าแรก ให้เหตุผลเฉพาะรายการที่ระบบถาม แล้วแตะ แจ้งว่าบันทึกรับของครบ

รับการแจ้งเตือนบนมือถือ: แตะ ฉัน แตะ เปิดการแจ้งเตือน ในการ์ด “แจ้งเตือนตอนเช้า”มีข้อสงสัย ติดต่อประสานงานขาย · คู่มือ: /docs/pilot/branch_guide.html
