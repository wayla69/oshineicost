ระหว่างการนำร่อง (สัปดาห์ที่ 1–4)

  • ทุกวัน: สาขาบันทึกและยืนยันใบตัดเบิกประจำวัน (เบิกใช้และของเสียพร้อมสาเหตุ) · ทุกรอบส่ง: สาขาสั่งสินค้าตามยอดแนะนำที่หักคงเหลือตามระบบแล้ว (แก้ไขได้พร้อมระบุเหตุผล) ต้องยืนยันใบตัดเบิกของวันนี้ก่อนส่ง และส่งใบสั่งซื้อก่อนเวลาตัดรอบ 13:15 สองวันก่อนวันส่ง · คลังดำเนินการภายใน 14:00 ของวันตัดรอบ · สาขาบันทึกรับสินค้าในระบบ
  • ทุกครั้งที่ตรวจนับปลายงวด: สาขาระบุเหตุผลของผลต่าง และยืนยันการบันทึกรับสินค้าครบถ้วน
  • ทุกสิ้นเดือนหลังสาขายืนยันรับสินค้าครบ: บัญชีดาวน์โหลดใบสรุปตัดเบิกรายสาขา (Excel) ที่ ปิดงวดเดือน → ใบสรุปตัดเบิก ไปบันทึกในระบบบัญชี แล้วติ๊ก “บันทึกเข้าระบบบัญชีแล้ว” ระบบจึงล็อกงวดนั้นไม่ให้เพิ่มใบรับสินค้า
  • ทุกวันจันทร์: Ops, SCM และ IT ประชุมทบทวน 30 นาที โดยใช้ข้อมูลจาก หน้างาน → สาขานำร่อง 4 สาขา · ใบสั่งซื้อ → ตรวจสอบการสั่ง · ปิดงวดเดือน → สรุปผลต่างรายเดือน เพื่อปรับหน่วยครัว เกณฑ์ และเหตุผล
  • ทบทวนสต๊อกสำรอง (safety stock) ของสินค้าชั้น A ซึ่งปัจจุบันอยู่ที่ประมาณ 50% ของยอดพยากรณ์ 3 วัน และอาจสูงเกินไป

เกณฑ์การผ่าน (แผน §7.3)

ตัวชี้วัดเกณฑ์แหล่งข้อมูล
ใบตัดเบิกครบทุกวันไม่น้อยกว่า 95% ของวันในช่วงนำร่องใบตัดเบิกที่ยืนยันแล้ว (ตรงวันหรือล่าช้า) เทียบกับจำนวนวัน
ยืนยันใบตัดเบิกภายในวันไม่น้อยกว่า 90% ของใบที่ยืนยันแล้วใบที่ยืนยันในวันเดียวกัน ไม่นับใบที่ทำย้อนหลังหรือถูกเปิดแก้ไขแล้วยืนยันใหม่
ผลต่างที่มีเหตุผลไม่น้อยกว่า 80% ของรายการที่เกินเกณฑ์หน้าผลต่างการใช้
ความคลาดเคลื่อนของการพยากรณ์ชั้น Aไม่เกิน 15% (MAPE รายสัปดาห์)backtest ของ Forecast Engine
หากผ่านทุกเกณฑ์ ขยายผลไปยังทุกสาขา master แล้วจึงขยายไปยังสาขา franchise · หากไม่ผ่าน ปรับปรุงแล้วนำร่องต่ออีก 2 สัปดาห์

สคริปต์วิดีโอสำหรับสาขา 5 นาที (ถ่ายทำบนโทรศัพท์มือถือจริง)

0:00–0:30 วัตถุประสงค์ คำบรรยาย: “ระบบคำนวณปริมาณวัตถุดิบที่ใช้จากยอดขาย สาขาบันทึกใบตัดเบิกประจำวัน แล้วระบบจะแนะนำยอดสั่งโดยหักคงเหลือตามระบบ และแสดงรายการที่ใช้เกินสูตร” (ภาพ: หน้างาน และชิป สาขาของฉัน 5 หน้า)
0:30–2:00 ตัดเบิก เข้าสู่ระบบ → หน้างาน → “ไปที่งาน →” ยืนยันใบตัดเบิก → เลือกโซนแช่แข็ง → กรอกเบิกใช้ของรายการแรก → กรอกของเสียหนึ่งรายการและเลือกสาเหตุ → ปิดแอปแล้วเปิดใหม่ เพื่อแสดงว่าร่างยังอยู่ → ยืนยันใบตัดเบิก
2:00–3:15 สั่งสินค้า สั่งสินค้า → ระบบเลือกรอบให้แล้ว → หน้าสั่งจากส่วนกลาง → อ่านบรรทัด “พยากรณ์ + สำรอง − คงเหลือที่คาดการณ์” → แก้ไขหนึ่งรายการเป็น 2 เท่า → ระบบขอเหตุผล → เลือก “มีงาน / โปรโมชัน / ลูกค้าจองกลุ่ม” → ส่งให้ส่วนกลาง · แสดงหน้าจัดซื้อในพื้นที่โดยย่อ
3:15–4:00 รับสินค้า เมื่อสินค้ามาถึง → รับสินค้า → ใบสั่งซื้อที่รอรับสินค้า → เลือกใบ → แก้ไขหนึ่งรายการที่ได้รับไม่ครบ → บันทึกรับสินค้า · สินค้าที่จัดซื้อเองจากตลาดบันทึกในหน้าเดียวกัน
4:00–4:45 ผลต่างการใช้ หลังส่งผลตรวจนับปลายงวด กด “ยืนยันว่ารับสินค้าของรอบนี้บันทึกครบแล้ว” ที่แสดงทันที → เปิด ผลต่างการใช้ → รายการแรกคือรายการที่มีมูลค่าผลต่างสูงสุด → เลือกเหตุผล “เสิร์ฟเกินปริมาณตามสูตร”
4:45–5:00 สรุป คำบรรยาย: “ยืนยันใบตัดเบิกทุกวัน และส่งใบสั่งซื้อให้ทันเวลาตัดรอบ 13:15 สองวันก่อนวันส่ง หากมีปัญหา กรุณาติดต่อ Sales Support”
