การเตรียมการ (สัปดาห์ที่ 0)

งานผู้รับผิดชอบตำแหน่งในแอป
เติมทะเบียนวัตถุดิบ (หน่วย โซน หน่วยที่นับ)ฝ่ายวิเคราะห์ฝ่ายวิเคราะห์ → ทะเบียนวัตถุดิบ
นำเข้าราคาซื้อจริงของงวดล่าสุดฝ่ายวิเคราะห์ / ประสานงานขายฝ่ายวิเคราะห์ → ราคารายเดือน
นำเข้าต้นทุนต่อจานของเดือน (ไฟล์ Excel ตรวจก่อนบันทึก ไม่มีขั้นประกาศใช้)ฝ่ายวิเคราะห์ฝ่ายวิเคราะห์ → ต้นทุนต่อจาน
นำเข้ารายงานไดกิโตะ กรุ๊ป (บัญชีสินค้า) และจับคู่รหัสกับรหัสสินค้าของไดกิโตะ กรุ๊ปฝ่ายวิเคราะห์ / ประสานงานขายประสานงานขาย → นำเข้าข้อมูลปิดงวด (ขั้นตอนที่ 2 และ 3)
สร้างบัญชีสาขา 4 บัญชี ชื่อผู้ใช้ wh_<ตัวย่อ> (บทบาท “สาขา” และระบุสาขา) และบัญชีเจ้าของสาขา own_<ตัวย่อ> ของสาขาแฟรนไชส์ (ขั้นตอนใน docs/ONBOARDING_30_BRANCHES.md)ผู้ดูแลระบบตั้งค่า → ผู้ใช้งาน
กำหนดวันสั่ง 3 รอบของ 4 สาขาประสานงานขายประสานงานขาย → รอบส่งของสาขา
อบรมสาขา (วิดีโอ 5 นาทีและคู่มือสาขา) อบรมคลัง 20 นาที และอบรมประสานงานขาย 1 ชั่วโมง คู่มืออยู่ที่ docs/pilot/ (สาขา · คลัง · ประสานงานขาย · บัญชี · เจ้าของสาขา)IT / ฝ่ายปฏิบัติการ/docs/pilot/
ตรวจนับสิ้นเดือน ต้นงวดครั้งแรก (นับครบทุกรายการ ใส่ 0 ถ้าไม่มีของ)สาขาสาขา → ตรวจนับสิ้นเดือน

ระหว่างการนำร่อง (สัปดาห์ที่ 1–4)

  • ทุกวัน: สาขาบันทึกและยืนยันใบตัดเบิกประจำวัน (เบิกใช้และของเสียพร้อมสาเหตุ) · ทุกรอบส่ง: สาขาสั่งสินค้าตามยอดแนะนำที่หักคงเหลือตามระบบแล้ว (แก้ไขได้พร้อมระบุเหตุผล) ต้องยืนยันใบตัดเบิกของวันนี้ก่อนส่ง และส่งใบสั่งซื้อก่อนเวลาตัดรอบ 13:15 สองวันก่อนวันส่ง · คลังยืนยันยอดส่งภายใน 14:00 ของวันตัดรอบ · สาขาบันทึกรับสินค้าในระบบ (ตอบ “รับครบ” หรือ “มีรายการไม่ครบ”)
  • ทุกครั้งที่ตรวจนับปลายงวด: สาขาระบุเหตุผลของผลต่าง และยืนยันการบันทึกรับสินค้าครบถ้วน
  • ทุกสิ้นเดือนหลังสาขายืนยันรับสินค้าครบ: บัญชีดาวน์โหลดใบสรุปตัดเบิกรายสาขา (Excel) ที่ บัญชี → ใบสรุปตัดเบิก ไปบันทึกในระบบบัญชี แล้วติ๊ก “บันทึกเข้าระบบบัญชีแล้ว” ระบบจึงล็อกงวดนั้นไม่ให้เพิ่มใบรับสินค้า
  • ทุกวันจันทร์: ฝ่ายปฏิบัติการ, SCM และ IT ประชุมทบทวน 30 นาที โดยใช้ข้อมูลจาก ปฏิบัติการ → การใช้งานทุกสาขา · ปฏิบัติการ → ตรวจสอบการสั่ง เพื่อปรับหน่วยครัว เกณฑ์ และเหตุผล
  • ทบทวนสต็อกสำรอง (safety stock) ของสินค้ากลุ่มมูลค่าสูง ซึ่งปัจจุบันคำนวณจากความผันผวนของการใช้คูณค่าสัมประสิทธิ์ของกลุ่ม (สูง 1.65 · กลาง 1.28 · ต่ำ 1.04) แล้วทบทวนว่าสูงเกินไปหรือไม่

เกณฑ์การผ่าน (แผน §7.3)

ตัวชี้วัดเกณฑ์แหล่งข้อมูล
ใบตัดเบิกครบทุกวันไม่น้อยกว่า 95% ของวันในช่วงนำร่องใบตัดเบิกที่ยืนยันแล้ว (ตรงวันหรือล่าช้า) เทียบกับจำนวนวัน
ยืนยันใบตัดเบิกภายในวันไม่น้อยกว่า 90% ของใบที่ยืนยันแล้วใบที่ยืนยันในวันเดียวกัน ไม่นับใบที่ทำย้อนหลังหรือถูกเปิดแก้ไขแล้วยืนยันใหม่
ผลต่างที่มีเหตุผลไม่น้อยกว่า 80% ของรายการที่ระบบถามเหตุผล (กลุ่มมูลค่าสูงและ 20 รายการที่ผลต่างเป็นเงินมากที่สุด)หน้าผลต่างการใช้
ความคลาดเคลื่อนของการพยากรณ์กลุ่มมูลค่าสูงไม่เกิน 15% (MAPE รายสัปดาห์)backtest ของ Forecast Engine
หากผ่านทุกเกณฑ์ ขยายผลไปยังทุกสาขา master แล้วจึงขยายไปยังสาขา franchise · หากไม่ผ่าน ปรับปรุงแล้วนำร่องต่ออีก 2 สัปดาห์ · ขั้นตอนเปิดใช้งาน 30 สาขา (รายชื่อสาขา สร้างบัญชี ข้อความแจก ตั้งวันส่งจากไฟล์) อยู่ใน docs/ONBOARDING_30_BRANCHES.md

สคริปต์วิดีโอสำหรับสาขา 5 นาที (ถ่ายทำบนโทรศัพท์มือถือจริง)

0:00–0:30 วัตถุประสงค์ คำบรรยาย: “สาขาบันทึกใบตัดเบิกประจำวัน ยอดสั่งแนะนำคำนวณจากใบตัดเบิกที่ยืนยันแล้วและหักคงเหลือตามระบบ และแสดงรายการที่เบิกเกินปกติ” (ภาพ: หน้าแรกของสาขา รายการ “ต้องทำวันนี้” ปุ่มใหญ่ 5 ปุ่ม และแถบล่าง 5 ปุ่ม: หน้าแรก · ตัดเบิก · สั่งสินค้า · รับสินค้า · ฉัน)
0:30–2:00 ตัดเบิก เข้าสู่ระบบ → หน้าแรก → ปุ่ม “ตัดเบิก” ที่แถบล่าง → แถบวัน (วันนี้ และวันที่ยังไม่ทำ) → เลือกโซนแช่แข็ง → กรอกเบิกใช้ของรายการแรก (ตัวเลขเทา “เมื่อวาน 3” คือครั้งก่อน) → กรอกของเสียหนึ่งรายการและเลือกสาเหตุ → ปิดแอปแล้วเปิดใหม่ เพื่อแสดงว่าร่างยังอยู่ → ยืนยันใบตัดเบิก (คำถามบอกจำนวนรายการที่ไม่ได้กรอก)
2:00–3:15 สั่งสินค้า สั่งสินค้า → เลือกรอบส่ง (รอบ ส่ง ส่งใบสั่งซื้อภายใน และสถานะเปิดรับ) → อ่านแนะนำและคงเหลือของรายการแรก แตะ “ดูที่มา” → แก้ไขหนึ่งรายการเป็น 2 เท่า → ระบบขอเหตุผล → เลือก “มีงาน / โปรโมชัน / ลูกค้าจองกลุ่ม” → ส่งใบสั่งซื้อ · แสดงหน้า “ซื้อเอง” โดยย่อ
3:15–4:00 รับสินค้า เมื่อสินค้ามาถึง → รับสินค้า → ใบสั่งซื้อที่คลังจัดส่งแล้ว → คำถาม “รับครบตามที่คลังส่งทุกรายการ?” → แตะ “มีรายการไม่ครบ” → ค้นหาและเลือกหนึ่งรายการ ใส่รับจริงและสาเหตุ → ติ๊ก “ตรวจสภาพและจำนวนครบแล้ว” → บันทึกรับสินค้า · สินค้าที่ซื้อเองบันทึกที่การ์ด “บันทึกสินค้าที่รับเอง”
4:00–4:45 ผลต่างการใช้ หลังส่งผลตรวจนับปลายงวด กด “ยืนยันรับสินค้าครบ” ที่แสดงทันที → แตะปุ่มใหญ่ ผลต่างการใช้ ที่หน้าแรก → แถบรายวัน: ยอดเบิก · ปกติของสาขา · ค่ากลางทุกสาขา → แถบสิ้นเดือน: เลือกเหตุผลของรายการที่ระบบถาม (ถามเฉพาะรายการมูลค่าสูง)
4:45–5:00 สรุป คำบรรยาย: “ยืนยันใบตัดเบิกทุกวัน และส่งใบสั่งซื้อให้ทันเวลาตัดรอบ 13:15 สองวันก่อนวันส่ง หากมีปัญหา · ติดต่อ ประสานงานขาย”

ต้นทุนต่อจานรายเดือน

  • ผู้นำเข้า: ฝ่ายวิเคราะห์ ที่ ฝ่ายวิเคราะห์ → ต้นทุนต่อจาน · ไม่มีขั้นประกาศใช้หรือรับทราบ
  • เมื่อ: ทุกเดือน เริ่มเดือน ก.ย. 2569 · หน้างานมีงาน “นำเข้าต้นทุนต่อจานเดือน…” จนทุกเมนูที่ขายในเดือนนั้นมีต้นทุน
  • เดือนที่ไม่นำเข้า: ใช้ต้นทุนของเดือนก่อนหน้า แยกตามรหัส · ผล: รายงานกำไร P&L เมนู ต้นทุนต่อหัว และความครอบคลุมต้นทุน ใช้ต้นทุนที่นำเข้าแทนต้นทุนตามสูตร

ภาคผนวก: ส่วนสูตร (Phase 2)

ใช้เมื่อผู้บริหารเปลี่ยนโหมดระบบเป็นเต็มระบบ · ในโหมดสต๊อกหน้าและงานเหล่านี้ไม่แสดง
งานผู้รับผิดชอบตำแหน่งในแอป
ตรวจรหัสสูตรเดิมที่ชื่อไม่ตรงกันฝ่ายวิเคราะห์ฝ่ายวิเคราะห์ → ความพร้อมและรหัสสูตรเดิม
นำเข้าสูตรกึ่งสำเร็จจากไฟล์ครัว และจับคู่สูตรที่เหลือ 15 สูตรฝ่ายวิเคราะห์ และครัวฝ่ายวิเคราะห์ → สูตรกึ่งสำเร็จ (ครัว: ครัว → สูตรกึ่งสำเร็จ)
จับคู่รหัสในสูตรกับรหัสสินค้าของไดกิโตะ กรุ๊ปฝ่ายวิเคราะห์ / ประสานงานขายประสานงานขาย → นำเข้าข้อมูลปิดงวด (ขั้นตอนที่ 3)
  • ผลต่างรายวันเทียบสูตร และภาพวิดีโอแถบรายงวด: ตัวเลข ใช้จริง · ตามสูตร · ผลต่าง → “ต้องให้เหตุผล N รายการ” → เหตุผล “เสิร์ฟเกินปริมาณตามสูตร”
