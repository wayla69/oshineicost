ระหว่าง pilot (สัปดาห์ 1–4)

  • ทุกวันสั่ง: สาขานับก่อนเปิด → สั่งตามแนะนำ (แก้พร้อมเหตุผล) → ส่ง · Sales Support ดำเนินการภายใน 14:00 · สาขารับของในระบบ
  • ทุกครั้งที่นับปลายงวด: สาขาใส่เหตุผลผลต่าง + ยืนยันรับของครบ
  • ทุกวันจันทร์: Ops + SCM + IT ทบทวน 30 นาที — ศูนย์สั่งสินค้า (Pilot · ตรวจการสั่ง · ผลต่าง) → ปรับหน่วยครัว / เกณฑ์ / เหตุผล
  • ทบทวนสำรอง (safety stock) ของชั้น A — ตอนนี้ราว 50% ของพยากรณ์ 3 วัน อาจสูงไป

สคริปต์วิดีโอสาขา 5 นาที (ถ่ายบนมือถือจริง)

0:00–0:30 ทำไม — “ระบบรู้ว่าเราใช้อะไรไปจากยอดขาย เรานับของที่เหลือ ระบบบอกว่าควรสั่งเท่าไร และบอกว่าตรงไหนใช้เกินสูตร” (ภาพ: หน้าสาขาของฉัน 4 แท็บ)
0:30–2:00 นับสต๊อก — เข้าระบบ → นับสต๊อก → เลือกโซนแช่แข็ง → หยิบแพ็คจริง กด + → พิมพ์ 2.5 → ติ๊กเฉพาะรายการบังคับ → ปิดแอปแล้วเปิดใหม่ให้เห็นว่าร่างยังอยู่ → ส่งผลนับ
2:00–3:15 สั่งของ — แท็บสั่งของ → รอบ 1 → อ่านบรรทัด “พยากรณ์ + สำรอง − คงเหลือคาด” → แก้หนึ่งรายการเพิ่ม 2 เท่า → ระบบขอเหตุผล → เลือก “มีงาน/จองกลุ่ม” → ส่งให้ส่วนกลาง
3:15–4:00 รับของ — ของมาถึง → ของมาถึงแล้ว — รับของ → แก้หนึ่งรายการที่มาไม่ครบ → บันทึก · ซื้อเองที่ตลาด → แท็บรับของ
4:00–4:45 ผลต่างของฉัน — เปิดรอบล่าสุด → รายการบนสุด ฿ มากสุด → เลือกเหตุผล “ตักเกินสูตร” → ยืนยันรับของครบ
4:45–5:00 ปิด — “นับก่อนเปิดร้านทุกวันสั่ง ใช้เวลาไม่เกิน 20 นาที — ถ้าติดอะไรถาม Sales Support”
