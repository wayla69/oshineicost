นำเข้าสูตรกึ่งสำเร็จจากไฟล์ครัว และจับคู่สูตรที่เหลือ 15 สูตรฝ่ายวิเคราะห์ และครัวงานประจำเดือน → สูตรกึ่งสำเร็จ (ครัว: ปุ่ม สูตรกึ่งสำเร็จ)

ระหว่างการนำร่อง (สัปดาห์ที่ 1–4)

  • ทุกวัน: สาขาบันทึกและยืนยันใบตัดเบิกประจำวัน (เบิกใช้และของเสียพร้อมสาเหตุ) · ทุกรอบส่ง: สาขาสั่งสินค้าตามยอดแนะนำที่หักคงเหลือตามระบบแล้ว (แก้ไขได้พร้อมระบุเหตุผล) ต้องยืนยันใบตัดเบิกของวันนี้ก่อนส่ง และส่งใบสั่งซื้อก่อนเวลาตัดรอบ 13:15 สองวันก่อนวันส่ง · คลังยืนยันยอดส่งภายใน 14:00 ของวันตัดรอบ · สาขาบันทึกรับสินค้าในระบบ (ตอบ “รับครบ” หรือ “มีรายการไม่ครบ”)
  • ทุกครั้งที่ตรวจนับปลายงวด: สาขาระบุเหตุผลของผลต่าง และยืนยันการบันทึกรับสินค้าครบถ้วน
  • ทุกสิ้นเดือนหลังสาขายืนยันรับสินค้าครบ: บัญชีดาวน์โหลดใบสรุปตัดเบิกรายสาขา (Excel) ที่ ปิดงวดเดือน → ใบสรุปตัดเบิก ไปบันทึกในระบบบัญชี แล้วติ๊ก “บันทึกเข้าระบบบัญชีแล้ว” ระบบจึงล็อกงวดนั้นไม่ให้เพิ่มใบรับสินค้า
  • ทุกวันจันทร์: ฝ่ายปฏิบัติการ, SCM และ IT ประชุมทบทวน 30 นาที โดยใช้ข้อมูลจาก หน้างาน → สาขานำร่อง 4 สาขา · ใบสั่งซื้อ → ตรวจสอบการสั่ง · ปิดงวดเดือน → สรุปผลต่างรายเดือน เพื่อปรับหน่วยครัว เกณฑ์ และเหตุผล
  • ทบทวนสต็อกสำรอง (safety stock) ของสินค้าชั้น A ซึ่งปัจจุบันอยู่ที่ประมาณ 50% ของยอดพยากรณ์ 3 วัน และอาจสูงเกินไป

เกณฑ์การผ่าน (แผน §7.3)

ตัวชี้วัดเกณฑ์แหล่งข้อมูล
ใบตัดเบิกครบทุกวันไม่น้อยกว่า 95% ของวันในช่วงนำร่องใบตัดเบิกที่ยืนยันแล้ว (ตรงวันหรือล่าช้า) เทียบกับจำนวนวัน
ยืนยันใบตัดเบิกภายในวันไม่น้อยกว่า 90% ของใบที่ยืนยันแล้วใบที่ยืนยันในวันเดียวกัน ไม่นับใบที่ทำย้อนหลังหรือถูกเปิดแก้ไขแล้วยืนยันใหม่
ผลต่างที่มีเหตุผลไม่น้อยกว่า 80% ของรายการที่ระบบถามเหตุผล (กลุ่มมูลค่าสูงและ 20 รายการที่ผลต่างเป็นเงินมากที่สุด)หน้าผลต่างการใช้
ความคลาดเคลื่อนของการพยากรณ์ชั้น Aไม่เกิน 15% (MAPE รายสัปดาห์)backtest ของ Forecast Engine
หากผ่านทุกเกณฑ์ ขยายผลไปยังทุกสาขา master แล้วจึงขยายไปยังสาขา franchise · หากไม่ผ่าน ปรับปรุงแล้วนำร่องต่ออีก 2 สัปดาห์ · ขั้นตอนเปิดใช้งาน 30 สาขา (รายชื่อสาขา สร้างบัญชี ข้อความแจก ตั้งวันส่งจากไฟล์) อยู่ใน docs/ONBOARDING_30_BRANCHES.md

สคริปต์วิดีโอสำหรับสาขา 5 นาที (ถ่ายทำบนโทรศัพท์มือถือจริง)

0:00–0:30 วัตถุประสงค์ คำบรรยาย: “ระบบคำนวณปริมาณวัตถุดิบที่ใช้จากยอดขาย สาขาบันทึกใบตัดเบิกประจำวัน แล้วยอดสั่งแนะนำหักคงเหลือตามระบบ และแสดงรายการที่ใช้เกินสูตร” (ภาพ: หน้างาน และแถบล่าง 5 ปุ่ม: หน้างาน · ตัดเบิก · สั่งสินค้า · รับสินค้า · ผลต่าง)
0:30–2:00 ตัดเบิก เข้าสู่ระบบ → หน้างาน → “ไปที่งาน →” → แถบวัน (วันนี้ และวันที่ยังไม่ทำ) → เลือกโซนแช่แข็ง → กรอกเบิกใช้ของรายการแรก (ตัวเลขเทา “เมื่อวาน 3” คือครั้งก่อน) → กรอกของเสียหนึ่งรายการและเลือกสาเหตุ → ปิดแอปแล้วเปิดใหม่ เพื่อแสดงว่าร่างยังอยู่ → ยืนยันใบตัดเบิก (คำถามบอกจำนวนรายการที่ไม่ได้กรอก)
2:00–3:15 สั่งสินค้า สั่งสินค้า → เลือกรอบส่ง (รอบ ส่ง สั่งภายใน และสถานะเปิดรับ) → อ่านแนะนำและคงเหลือของรายการแรก แตะ “ดูที่มา” → แก้ไขหนึ่งรายการเป็น 2 เท่า → ระบบขอเหตุผล → เลือก “มีงาน / โปรโมชัน / ลูกค้าจองกลุ่ม” → ส่งใบสั่งซื้อ · แสดงหน้า “ซื้อเอง” โดยย่อ
3:15–4:00 รับสินค้า เมื่อสินค้ามาถึง → รับสินค้า → ใบสั่งซื้อที่คลังจัดส่งแล้ว → คำถาม “รับครบตามที่คลังส่งทุกรายการ?” → แตะ “มีรายการไม่ครบ” → ค้นหาและเลือกหนึ่งรายการ ใส่รับจริงและสาเหตุ → ติ๊ก “ตรวจสภาพและจำนวนครบแล้ว” → บันทึกรับสินค้า · สินค้าที่ซื้อเองบันทึกที่การ์ด “บันทึกสินค้าที่รับเอง”
4:00–4:45 ผลต่างการใช้ หลังส่งผลตรวจนับปลายงวด กด “ยืนยันรับสินค้าครบ” ที่แสดงทันที → เปิด ผลต่างการใช้ → แถบรายงวด: ตัวเลข ใช้จริง · ตามสูตร · ผลต่าง → แตะ “ต้องให้เหตุผล N รายการ” → เลือกเหตุผล “เสิร์ฟเกินปริมาณตามสูตร” (ถามเฉพาะรายการมูลค่าสูง)
4:45–5:00 สรุป คำบรรยาย: “ยืนยันใบตัดเบิกทุกวัน และส่งใบสั่งซื้อให้ทันเวลาตัดรอบ 13:15 สองวันก่อนวันส่ง หากมีปัญหา · ติดต่อ ประสานงานขาย”
