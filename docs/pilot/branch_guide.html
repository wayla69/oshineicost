คู่มือการใช้งานสำหรับสาขา

เข้าสู่ระบบด้วยบัญชีสาขา (สาขาละ 1 บัญชี) บนโทรศัพท์มือถือ แล้วเลือกเมนู “สาขาของฉัน” (รายการเดียวในเมนูซ้าย) หน้าแรกคือ หน้างาน ซึ่งแสดงงานของวันนี้ กด “ไปที่งาน →” หรือเลือกหัวข้อ สาขาของฉัน ที่แถบด้านบน ซึ่งมี 5 หน้า ได้แก่ ตัดเบิก · สั่งสินค้า · รับสินค้า · ผลต่างการใช้ · ตรวจนับสิ้นเดือน · บนโทรศัพท์มีแถบล่าง 5 ปุ่มกดด้วยนิ้วโป้ง ได้แก่ หน้างาน · ตัดเบิก · สั่งสินค้า · รับสินค้า · ผลต่าง

1. ตัดเบิก (ทุกวัน) บันทึกและยืนยันก่อนส่งใบสั่งซื้อของวันนั้น

  1. เลือกวันที่แถบวันด้านบน (7 วันล่าสุด) จุดสีบอกสถานะของแต่ละวัน ได้แก่ ยืนยันแล้ว · ยืนยันล่าช้า · ร่าง · ยังไม่บันทึก
  2. กรอกช่อง เบิกใช้ ตามจำนวนที่ครัวเบิกไปใช้ในวันนั้น และช่อง ของเสีย ตามจำนวนที่ทิ้ง เน่าเสีย หมดอายุ หรือเสียหาย ตามหน่วยที่แสดงข้างช่อง (แพ็ค / ขวด / ถุง) แพ็คที่ไม่เต็มให้ระบุเป็นทศนิยมได้ เช่น 0.5 รายการที่ไม่ได้ใช้ให้เว้นว่างไว้
  3. รายการที่มีของเสียต้องเลือก สาเหตุ (ของเสีย / เน่าเสีย · หมดอายุ · หก / ตก / แตก · ตัดแต่งเกินสูตร · อื่น ๆ) หากเลือก “อื่น ๆ” ต้องระบุคำอธิบาย
  4. ใต้ชื่อวัตถุดิบแสดง คงเหลือตามระบบ (ผลตรวจนับสิ้นเดือน + รับเข้า − ใบตัดเบิกที่ยืนยันแล้ว) และค่าเฉลี่ยการเบิกใช้ 7 วัน ใช้ตรวจว่าจำนวนที่กรอกสมเหตุสมผล บันทึกร่างให้ขณะกรอก ข้อมูลไม่หายแม้สัญญาณขาด
  5. เมื่อกรอกครบแล้วกด ยืนยันใบตัดเบิก ใบที่ยืนยันแล้วแก้ไขไม่ได้ หากต้องแก้ไข · แจ้งประสานงานขายให้เปิดแก้ไข แล้วสาขาแก้ไขและยืนยันใหม่
  6. ต้องยืนยันใบตัดเบิกของวันนี้ก่อนจึงส่งใบสั่งซื้อได้ ใบตัดเบิกของวันก่อนหน้าที่ยังไม่ได้ทำให้ทำย้อนหลัง รับได้แต่นับเป็น “ยืนยันล่าช้า” และคงเหลือตามระบบอาจสูงกว่าจริง

2. สั่งสินค้า ส่งก่อน 13:15 สองวันก่อนวันส่ง

  1. เลือกรอบส่งที่ปุ่มด้านบน (เช่น “รอบ 1 · ส่งวันพุธ 7/10 · ตัดรอบ วันจันทร์ 13:15”) หน้านี้เลือกรอบส่งที่ใกล้ที่สุดและยังไม่ตัดรอบให้ก่อน รอบส่งวันอังคารต้องส่งใบสั่งซื้อก่อนวันเสาร์ 13:15
  2. ยอดแนะนำหัก คงเหลือตามระบบ (ผลตรวจนับสิ้นเดือน + รับเข้า − ใบตัดเบิกที่ยืนยันแล้ว) ออกจากยอดพยากรณ์ + สต็อกสำรอง แล้วปัดเป็นหน่วยสั่ง ไม่ต้องนับก่อนสั่ง ช่องคงเหลือตามระบบแสดงอยู่ข้างแต่ละรายการ
  3. กรอกช่อง สั่ง ตามจำนวนที่ต้องการ บันทึกร่างให้ขณะกรอก ข้อมูลไม่หายแม้สัญญาณขาด
  4. หากคาดว่ายอดขายรอบนี้จะต่างจากปกติ (มีงาน โปรโมชัน ลูกค้าจอง วันหยุดยาว) ให้ระบุ % ที่คาดว่าจะเพิ่มหรือลด พร้อมเหตุผลในกล่อง “คาดว่ายอดขายรอบนี้จะต่างจากปกติหรือไม่” แล้วกด ใช้กับยอดแนะนำ ยอดแนะนำทุกรายการคำนวณใหม่ (รายการที่สาขาพิมพ์เองไว้แล้วคงเดิม) หรือกด คำนวณจากจำนวนลูกค้า กรอกจำนวนลูกค้าที่คาดต่อวัน แล้วแปลงเป็น % ส่วนที่เพิ่มตามนี้ไม่ต้องให้เหตุผลรายบรรทัด
  5. หน้า สั่งจากไดกิโตะ แสดงวัตถุดิบในบัญชีสินค้าส่วนกลาง หน้า สาขาซื้อเอง ใช้ประกอบการซื้อของสาขา ไม่ส่งเข้าใบสั่งซื้อ
  6. ช่องสั่งแก้ไขได้ หากต่างจากยอดแนะนำเกิน 20% ต้องเลือกเหตุผล เช่น มีงาน / โปรโมชัน / ลูกค้าจองกลุ่ม หรือคงเหลือจริงมากกว่าตามระบบ
  7. กด ส่งใบสั่งซื้อ แล้วคลังจัดส่ง สาขากด เปิดแก้ไข ได้จนกว่าคลังยืนยันยอดส่ง
  8. ปุ่มส่งใช้ไม่ได้จนกว่าจะยืนยันใบตัดเบิกของวันนี้ มีลิงก์ “ไปที่ตัดเบิก” ให้กดได้ทันที
  9. หากส่งหลังเวลาตัดรอบ รับใบสั่งซื้อได้ แต่มีค่าปรับล่าช้าที่ต้องชำระให้คลังภายนอก และต้องกดยืนยันก่อนส่ง ใบนั้นแสดงป้าย “ส่งล่าช้า (มีค่าปรับ)”

3. รับสินค้า ทุกครั้งที่สินค้าเข้าร้าน

  • สินค้าตามใบสั่งซื้อ: หน้า รับสินค้า → รายการ ใบสั่งซื้อที่รอรับสินค้า → เลือกใบสั่งซื้อ → ตรวจสินค้า แก้ช่อง รับจริง หากรับได้น้อยกว่า ส่งจริง (จำนวนที่คลังส่ง) ให้เลือกสาเหตุของส่วนต่าง ส่วนต่างเป็นเคลมถึงประสานงานขายในการบันทึกครั้งเดียวกัน แล้วติ๊กยืนยันว่าตรวจสภาพและจำนวนครบ จึงกด บันทึกรับสินค้า (ยืนยันครั้งเดียว) · หรือกด “รับสินค้า →” ที่ประวัติใบสั่งซื้อในหน้าสั่งสินค้า
  • สินค้าที่สาขาซื้อเองหรือไม่อยู่ในใบสั่งซื้อ: หน้า รับสินค้า ส่วนบันทึกด้วยตนเองด้านล่าง → ระบุวันที่ → เลือกวัตถุดิบและจำนวน → บันทึกรับสินค้า
  • หากไม่บันทึกรับสินค้า ผลต่างจะแสดงเป็น “ใช้น้อยกว่าสูตร” ซึ่งไม่ตรงกับความจริง
  • สินค้าชำรุด เสีย หรือส่งผิด: หากพบในวันรับ ให้ใส่จำนวนที่ใช้ไม่ได้เป็นส่วนต่างในฟอร์มรับสินค้า แต่หากพบภายหลัง ให้กด แจ้งเคลม (การ์ด “แจ้งเคลมสินค้า” ในหน้าเดียวกัน) ใส่จำนวนและสาเหตุของแต่ละรายการ แล้วกด ส่งแจ้งเคลม ไม่ต้องอัปโหลดรูปในระบบ ให้ส่งรูปถ่ายสินค้าที่เคลมให้ประสานงานขายทางไลน์ ประสานงานขายจะพิจารณาและแจ้งผลที่การ์ดเดิม เคลมที่แจ้งขณะรับสินค้า สินค้าที่รับได้บันทึกตามจำนวนที่ได้รับจริงอยู่แล้ว เคลมที่แจ้งภายหลัง เมื่ออนุมัติ ปรับให้อัตโนมัติ (หักจำนวนที่อนุมัติออกจากรับเข้า) ไม่ต้องแก้ใบรับเอง
  • รายการที่รับไว้ครบโดยไม่ได้แจ้งเคลมในวันรับ หากแจ้งเคลมภายหลัง ประสานงานขายอาจไม่สามารถดำเนินการได้

4. ผลต่างการใช้ รายวัน · หลังส่งผลตรวจนับปลายงวด

  • หน้านี้มี 3 มุมมอง: รายงวด (ใช้จริง เทียบสูตร) · รายวัน (ตัดเบิกเทียบสูตร) · สิ้นเดือน (คงเหลือตามระบบเทียบนับจริง)
  • รายวัน: เทียบมูลค่าที่เบิกในใบตัดเบิกที่ยืนยันแล้ว (เบิกใช้ + ของเสีย) กับมูลค่าตามสูตรจากยอดขายของวันนั้น กดที่วันเพื่อดูรายการวัตถุดิบ หากรายการชั้น A เบิกเกินสูตรมากกว่า 20% ติดต่อกัน 3 วันขายขึ้นไป แสดงสัญญาณเตือน วันที่ใบตัดเบิกยังไม่ยืนยันจะไม่มีตัวเลขเปรียบเทียบ
  • สิ้นเดือน: คงเหลือตามระบบ = ยกมา + รับเข้า + เคลม/ปรับ − ตัดเบิก − ของเสีย เทียบกับสินค้านับจริงตอนปลายงวด รายการที่เกินเกณฑ์ต้องเลือกเหตุผล และดาวน์โหลดเป็น Excel ได้
  • รายงวด: ปริมาณใช้จริง = ต้นงวด + รับเข้า − ปลายงวด เทียบกับปริมาณตามสูตรจากยอดขายในช่วงเดียวกัน
  • รายการที่เกินเกณฑ์เรียงตามมูลค่า ต้องเลือกเหตุผลทุกรายการ เช่น วัตถุดิบเสีย / ทิ้ง · หมดอายุ · ชิม / อาหารพนักงาน · เสิร์ฟเกินปริมาณตามสูตร · โอนให้สาขาอื่น · ตรวจนับผิด
  • เมื่อบันทึกรับสินค้าครบแล้ว กด ยืนยันรับสินค้าครบ (หลังส่งผลตรวจนับปลายงวด มีปุ่มนี้ให้ทันทีในหน้าตรวจนับสิ้นเดือน) ก่อนยืนยัน งวดนั้นแสดงสถานะ “ยังไม่สมบูรณ์”

5. ตรวจนับสิ้นเดือน วันที่ 1 ของเดือน

  1. นับครบทุกรายการ ใช้สำหรับปิดงวดเดือนและเทียบกับใบตัดเบิกเท่านั้น
  2. เลือกโซน ได้แก่ แช่แข็ง · แช่เย็น · ของแห้ง · บาร์น้ำ
  3. กรอกจำนวนตามหน่วยที่นับจริง (แพ็ค / ขวด / ถุง) โดยกดปุ่ม − / + หรือพิมพ์ตัวเลข แพ็คที่ไม่เต็มให้ระบุเป็นทศนิยมได้ เช่น 0.5
  4. ตัวเลขสีจางคือผลตรวจนับครั้งก่อน หากมีเวลาจำกัด ให้เลือก “เฉพาะรายการบังคับ”
  5. บันทึกร่างให้ขณะกรอก ข้อมูลไม่หายแม้สัญญาณขาด ตรวจนับครบแล้วกด ส่งผลตรวจนับ ส่งแล้วแก้ไม่ได้ ต้องการแก้ให้ตรวจนับใหม่
การตรวจนับครั้งแรกเป็นต้นงวด ครั้งต่อไปเป็นปลายงวด และใช้เป็นต้นงวดของเดือนถัดไปอัตโนมัติ การเบิกใช้รายวันบันทึกในหน้าตัดเบิก ไม่ต้องนับสินค้าก่อนสั่ง

ข้อแนะนำ

  • ยืนยันใบตัดเบิกทุกวัน (เป้าหมายครบไม่น้อยกว่า 95% ของวัน และยืนยันภายในวันเดียวกันไม่น้อยกว่า 90%) · ตรวจนับสิ้นเดือนให้นับก่อนรับสินค้าของวันนั้น
  • หากมีเวลาจำกัดในการตรวจนับสิ้นเดือน ให้ตรวจนับรายการบังคับก่อน แล้วจึงตรวจนับรายการอื่น
  • หากระบบแสดง “แปลงหน่วยไม่ได้” แสดงว่าหน่วยนั้นยังไม่มีในระบบ · แจ้งฝ่ายวิเคราะห์ (ผ่าน ประสานงานขาย ได้) ให้เพิ่มกฎหน่วย (หัวข้อ ข้อมูลตั้งต้น → หน่วยและการแปลง)
  • หากมีข้อสงสัยเกี่ยวกับยอดแนะนำ ให้ดูบรรทัดรายละเอียดใต้ชื่อสินค้า (พยากรณ์ + สำรอง − คงเหลือที่คาดการณ์) ก่อนแก้ไข
  • บัญชีสาขาบันทึกได้ทันทีหลังเข้าสู่ระบบ (ยืนยันใบตัดเบิก ส่งผลตรวจนับ ส่งใบสั่งซื้อ บันทึกรับสินค้า) ไม่ต้องปลดล็อกเครื่องและไม่ต้องใช้รหัสใด ๆ เพิ่ม
  • เครื่องจำการเข้าสู่ระบบไว้ 30 วัน และติดไอคอนแอปบนหน้าจอโทรศัพท์ได้ (เมนูของเบราว์เซอร์ → “เพิ่มไปยังหน้าจอหลัก”) เปิดครั้งต่อไปจะเต็มจอเหมือนแอป
