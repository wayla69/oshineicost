สาขาของฉัน — คู่มือ 1 หน้า

เข้าระบบด้วยบัญชีสาขา (1 บัญชีต่อสาขา) บนมือถือ → เมนู “สาขาของฉัน” มี 4 แท็บ: นับสต๊อก · สั่งของ · รับของ · ผลต่างของฉัน

1. นับสต๊อก ทุกวันสั่ง ก่อนเปิดร้าน

  1. เลือกโซน: แช่แข็ง · แช่เย็น · ของแห้ง · บาร์น้ำ
  2. ใส่จำนวนเป็นหน่วยที่หยิบจริง (แพ็ค / ขวด / ถุง) — กด − / + หรือพิมพ์ เศษแพ็คใส่ทศนิยมได้ (0.5)
  3. ตัวเลขจาง ๆ คือครั้งก่อน · ติ๊ก “เฉพาะรายการบังคับ” ถ้ารีบ
  4. ระบบบันทึกร่างให้เอง สัญญาณหลุดไม่หาย → นับครบแล้วกด ส่งผลนับ (ส่งแล้วแก้ไม่ได้ — นับใหม่ได้)
ครั้งแรก = ต้นงวด · ครั้งต่อไป = ปลายงวดและต้นงวดใหม่อัตโนมัติ

2. สั่งของ วันสั่งรอบ 1 · รอบ 2 · แซลมอน

  1. เลือกรอบ → ระบบแนะนำยอด = พยากรณ์ + สำรอง − ของที่คาดว่าเหลือ (จากที่นับ) ปัดเป็นแพ็ค
  2. ช่องขวาคือยอดที่จะสั่ง แก้ได้ — ถ้าต่างจากแนะนำเกิน 20% ต้องเลือกเหตุผล (มีงาน/จองกลุ่ม, ของเหลือมากกว่าที่ระบบเห็น …)
  3. กด ส่งให้ส่วนกลาง → Sales Support ดำเนินการต่อ · แก้ได้ (เปิดแก้) จนกว่าส่วนกลางกดดำเนินการ
  4. ยังไม่ได้นับ = สั่งได้ แต่ยอดไม่หักสต๊อก (ขึ้นป้ายเหลือง)

3. รับของ ทุกครั้งที่ของเข้าร้าน

  • ของจากออเดอร์: แท็บสั่งของ → ของมาถึงแล้ว — รับของ → ใส่จำนวนที่ได้จริง → บันทึก
  • ของที่ซื้อเอง/นอกออเดอร์: แท็บ รับของ → วันที่ → เลือกวัตถุดิบ + จำนวน → บันทึกรับของ
  • ไม่บันทึกรับของ = ผลต่างจะเห็นว่า “ใช้น้อยกว่าสูตร” ผิดความจริง

4. ผลต่างของฉัน หลังส่งผลนับปลายงวด

  • ใช้จริง = ต้น + รับเข้า − ปลาย เทียบ “ตามสูตร” จากยอดขายช่วงเดียวกัน
  • รายการที่ต่างเกินเกณฑ์เรียงตาม ฿ — เลือกเหตุผลทุกรายการ (ของเสีย, หมดอายุ, ชิม/อาหารพนักงาน, ตักเกินสูตร, โอนสาขา, นับผิด …)
  • บันทึกรับของครบแล้วกด ยืนยันว่ารับของรอบนี้บันทึกครบแล้ว — ก่อนนั้นรอบจะขึ้น “ยังไม่สมบูรณ์”

เคล็ดลับ

  • นับก่อนเปิดร้านและก่อนของเข้า — ระบบถือว่าตัวเลขที่นับคือของก่อนขายวันนั้น
  • เป้าเวลานับ ≤ 20 นาที · นับรายการบังคับก่อน แล้วค่อยรายการอื่น
  • ขึ้น “แปลงหน่วยไม่ได้” = หน่วยนั้นยังไม่มีในระบบ แจ้ง Sales Support / BoM Center เพิ่มกฎหน่วย
  • สงสัยยอดแนะนำ: ดูบรรทัดเล็กใต้ชื่อ (พยากรณ์ + สำรอง − คงเหลือคาด) ก่อนแก้
