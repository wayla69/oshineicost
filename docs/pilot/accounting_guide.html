คู่มือบัญชี: ใบสรุปตัดเบิกและใบตัดเบิกรายวัน

สำหรับบัญชีที่นำตัวเลขวัตถุดิบที่ใช้จริงของแต่ละสาขาไปบันทึกในระบบบัญชี · เมนูซ้าย “วัตถุดิบและใบสั่งซื้อ” → ชิป ปิดงวดเดือน → ใบสรุปตัดเบิก · บัญชีไม่ต้องคำนวณเอง ระบบจัดทำไฟล์ Excel ให้ทุกสาขา

ที่มาของตัวเลข

  • ใบตัดเบิกรายวัน: สาขาบันทึกทุกวันว่าครัวเบิกใช้วัตถุดิบอะไรเท่าไร และมีของเสียหรือทิ้งเท่าไร (ของเสียต้องระบุสาเหตุ) แล้วกดยืนยัน ใบที่ยืนยันแล้วแก้ไขไม่ได้ หากต้องแก้ไข ประสานงานขายเปิดแก้ไขพร้อมเหตุผลและระบบบันทึกประวัติไว้ ใบที่ยืนยันหลังวันที่ของใบมีป้าย “ล่าช้า”
  • ผลตรวจนับ ต้นงวด / ปลายงวด: สาขานับวัตถุดิบทุกรายการวันที่ 1 ของเดือนและวันที่ 1 ของเดือนถัดไป
  • ใบสรุปตัดเบิก: ตัวเลขใช้จริงของงวดหนึ่ง คำนวณจากผลตรวจนับและใบรับสินค้า ตัดเบิก (ใช้จริง) = ยกมา (ต้นงวด) + รับเข้า + เคลม/ปรับ − คงเหลือ (ปลายงวด) ราคาต่อหน่วยคือราคาซื้อจริงของเดือนที่งวดสิ้นสุด
  • กระทบยอด: ระบบนำใบตัดเบิกรายวันมาคำนวณสินค้าคงเหลือตามระบบ แล้วเทียบกับสินค้าที่สาขานับจริงปลายงวด เพื่อให้เห็นว่าใบตัดเบิกกับของจริงตรงกันหรือไม่

งานสิ้นเดือน

  1. รอให้สาขาหรือประสานงานขายกด ยืนยันรับสินค้าครบ ของงวดนั้น (หน้างานของบัญชีแสดงรายการ “ดาวน์โหลดใบสรุปตัดเบิกและบันทึกเข้าระบบบัญชี” เมื่อพร้อม) ระบบดาวน์โหลดไฟล์ได้เมื่อยืนยันแล้วเท่านั้น
  2. เปิด ปิดงวดเดือน → ใบสรุปตัดเบิก เลือกสาขาและงวด (ต้นงวด → ปลายงวด) ระบบเลือกงวดล่าสุดที่ยืนยันแล้วและยังไม่บันทึกให้ก่อน
  3. ตรวจป้ายด้านบน: ใบตัดเบิกยืนยันแล้ว X/Y วัน · ขาดใบตัดเบิก N วัน · ผลต่างเกินเกณฑ์ N รายการ · ไม่มีราคา N รายการ ป้ายเหล่านี้เป็นคำเตือน ไม่ได้ห้ามดาวน์โหลด หากมีวันที่ขาดใบหรือผลต่างมาก ให้สอบถามประสานงานขายก่อนบันทึก
  4. กด ดาวน์โหลด Excel (สาขานี้) ได้ไฟล์ 3 แผ่นงาน หรือ ดาวน์โหลดทุกสาขา ได้ไฟล์ทั้งเดือน (แผ่นสรุปทุกสาขา แผ่นใบตัดเบิกรายวัน และแผ่นของแต่ละสาขา) สาขาที่ยังไม่ยืนยันรับสินค้าครบแสดงในแผ่นสรุปว่า “ยังไม่ยืนยันรับสินค้าครบ”
  5. บันทึกตัวเลขเข้าระบบบัญชี แล้วติ๊ก “บันทึกเข้าระบบบัญชีแล้ว” ของงวดนั้น (การติ๊กต้องปลดล็อกการบันทึกครั้งเดียวต่อเบราว์เซอร์ โดยขอรหัสจากเจ้าของระบบ) หลังติ๊ก หน้าจอแสดงป้าย “บัญชีบันทึกแล้ว เมื่อ … โดย …”

ใบตัดเบิกที่ยืนยันแล้วทั้งเดือน

ปุ่ม ใบตัดเบิกที่ยืนยันแล้วทั้งเดือน (Excel) บนหน้าเดียวกัน ให้ไฟล์ของทุกสาขาในเดือนของงวดที่เลือก แผ่น “ใบตัดเบิกที่ยืนยัน” เป็นตารางหนึ่งแถวต่อหนึ่งรายการต่อหนึ่งใบ ไม่มีแถวรวม จึงนำเข้าโปรแกรมบัญชีได้ตรง ๆ แผ่น “สรุปต่อสาขา” แสดงจำนวนใบ มูลค่าเบิกใช้ และมูลค่าของเสียของแต่ละสาขา ไฟล์ไม่รวมใบที่ยังเป็นร่างและใบที่ประสานงานขายเปิดแก้ไขอยู่

ความหมายของคอลัมน์

แผ่น “ใบตัดเบิกรายวัน” (ไฟล์ใบสรุปตัดเบิก) และ “ใบตัดเบิกที่ยืนยัน” (ไฟล์ทั้งเดือน) ใช้คอลัมน์ชุดเดียวกัน
คอลัมน์ความหมาย
วันที่ · สาขา · รหัส · วัตถุดิบวันที่ของใบตัดเบิก สาขา และรายการวัตถุดิบ
หน่วย · เบิกใช้ · ของเสียจำนวนเป็นหน่วยฐานของวัตถุดิบ (เช่น กรัม) เบิกใช้ = ที่ครัวใช้ ของเสีย = ที่เสียหรือทิ้ง
สาเหตุของเสียสาเหตุที่สาขาเลือก เช่น หมดอายุ หก/ตก/แตก (ถ้าเลือก “อื่น ๆ” มีคำอธิบายต่อท้าย)
ราคาต่อหน่วยราคาซื้อจริงต่อหน่วยฐานของเดือนที่ใบตัดเบิกระบุ ถ้ายังไม่มีราคาเว้นว่าง
มูลค่าเบิกใช้ · มูลค่าของเสียจำนวน × ราคาต่อหน่วย (บาท)
เลขที่ใบ · ยืนยันเมื่อ · ล่าช้าเลขที่ใบในระบบ เวลายืนยัน (เวลาไทย) และ “ล่าช้า” เมื่อยืนยันหลังวันที่ของใบ
แผ่น “สรุปเคลื่อนไหว” (ใบสรุปตัดเบิกเดิม) และแผ่น “กระทบยอด”
แผ่นงาน / คอลัมน์ความหมาย
สรุปเคลื่อนไหว: ยกมา · รับเข้า · เคลม/ปรับ · คงเหลือผลตรวจนับต้นงวด ใบรับสินค้า การปรับจากเคลมที่อนุมัติ (ติดลบ) และผลตรวจนับปลายงวด
สรุปเคลื่อนไหว: ตัดเบิก (ใช้จริง) · มูลค่าตัดเบิกยกมา + รับเข้า + เคลม/ปรับ − คงเหลือ และมูลค่าตามราคาซื้อจริง · ใช้บันทึกเข้าระบบบัญชี
กระทบยอด: ตัดเบิก (ใช้) · ของเสียรวมจากใบตัดเบิกรายวันที่ยืนยันแล้วในงวด
กระทบยอด: คงเหลือตามระบบยกมา + รับเข้า + เคลม/ปรับ − ตัดเบิก − ของเสีย
กระทบยอด: นับจริง · ผลต่างผลตรวจนับปลายงวด และผลต่าง = นับจริง − คงเหลือตามระบบ (ติดลบ = นับได้น้อยกว่าระบบ) พร้อมผลต่างเป็นมูลค่าและเปอร์เซ็นต์
กระทบยอด: ชั้น · สถานะ · เหตุผลชั้น A/B/C ตามมูลค่าที่เบิก เกณฑ์ผลต่าง A ±5% · B ±10% · C ±20% · สถานะ “ตรงกัน” “นับได้มากกว่าระบบ” “นับได้น้อยกว่าระบบ” “ตรวจนับไม่ครบ” · เหตุผลที่สาขาระบุสำหรับรายการที่เกินเกณฑ์

การล็อกหลังบันทึก

เมื่อติ๊ก “บันทึกเข้าระบบบัญชีแล้ว” ระบบล็อกงวดนั้น: ไม่รับใบรับสินค้าและการอนุมัติเคลมที่ลงวันที่ในงวด ไม่ให้ยืนยันหรือเปิดแก้ไขใบตัดเบิกที่ลงวันที่ในงวด และยกเลิกการยืนยันรับสินค้าครบไม่ได้ เพื่อไม่ให้ตัวเลขที่บัญชีบันทึกไปแล้วเปลี่ยน หากพบว่าต้องแก้ไข ให้บัญชียกเลิกการบันทึก (เอาเครื่องหมายติ๊กออก) ก่อน ประสานงานขายแก้ไขได้ แล้วบัญชีดาวน์โหลดและบันทึกใหม่ · วันตรวจนับปลายงวดเป็นวันแรกของงวดถัดไป ใบตัดเบิกของวันนั้นจึงไม่ถูกล็อกโดยงวดก่อน

สิ่งที่บัญชีไม่ต้องทำ

  • ไม่ต้องคำนวณตัดเบิกหรือหาราคาเอง ระบบคำนวณและแสดงที่มาของราคาในไฟล์
  • ไม่ต้องตามสาขาให้ยืนยันใบตัดเบิกหรือรับสินค้า เป็นหน้าที่ของประสานงานขายและ Ops (หน้างานของทั้งสองบทบาทแสดงสาขาที่ค้าง)
  • ไม่ต้องแก้ไขใบตัดเบิกของสาขา บัญชีดูและดาวน์โหลดได้เท่านั้น ไม่สามารถเปิดแก้ไขใบ
  • ไม่ต้องปลดล็อกการบันทึกเพื่อดูหรือดาวน์โหลด ปลดล็อกเฉพาะตอนติ๊ก “บันทึกเข้าระบบบัญชีแล้ว”
