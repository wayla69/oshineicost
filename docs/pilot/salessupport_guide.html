คู่มือ Sales Support: ใบสั่งซื้อและปิดงวดเดือน

สาขาส่งใบสั่งซื้อถึงส่วนกลาง และ Sales Support เป็นผู้ดำเนินการต่อ (การตัดสินใจของเจ้าของ §10-6) · เมนูซ้าย “วัตถุดิบและใบสั่งซื้อ” เปิดที่ หน้างาน (งานของวันนี้ พร้อมปุ่ม “ไปที่งาน →”) · งานประจำวันอยู่ที่ชิป ใบสั่งซื้อ → คิวใบสั่งซื้อ · งานสิ้นเดือนอยู่ที่ชิป ปิดงวดเดือน

งานประจำวัน

  1. ตรวจสอบคิว “รอดำเนินการ” ซึ่งเรียงตามวันส่ง ใบสั่งซื้อแต่ละใบแสดงสาขา รอบ มูลค่า และป้ายสถานะ ดังนี้
    • “สาขาแก้ไข N รายการ” หมายถึง สาขาสั่งต่างจากยอดแนะนำ พร้อมระบุเหตุผล
    • “ไม่หักยอดคงเหลือ” หมายถึง สาขายังไม่มีผลตรวจนับ ยอดสั่งอาจสูงเกินความจำเป็น
    • “ส่งหลัง 10:00” และ “ดำเนินการหลัง 14:00” หมายถึง เกินเวลาเป้าหมาย
  2. เปิดใบสั่งซื้อ เพื่อดูยอดแนะนำ ยอดที่สาขายืนยัน (พร้อมเหตุผลของสาขา) และช่อง “ส่งจริง” ซึ่งตั้งต้นเท่ากับยอดที่สาขายืนยัน
  3. หากจัดส่งตามยอดที่สาขายืนยันไม่ได้ ให้แก้ไขช่อง “ส่งจริง” และเลือกเหตุผล ได้แก่ ซัพพลายเออร์สินค้าขาด / ส่งได้ไม่ครบ · เปลี่ยนเป็นสินค้าทดแทน · ปรับตามขนาดแพ็ค / ขั้นต่ำ · รวมกับรอบอื่น · ส่วนกลางจัดส่งสินค้าในสต็อกแทน · อื่น ๆ (ต้องระบุคำอธิบาย)
  4. ระบุ เลขที่ PO แล้วกด ดำเนินการแล้ว หลังจากนั้นสาขาจะเปิดแก้ไขใบสั่งซื้อนั้นไม่ได้ และจะเห็นสถานะ “ส่วนกลางดำเนินการแล้ว”
  5. กด สรุปรวมตามผู้จำหน่ายและวันส่ง เพื่อดูยอดรวมของวัตถุดิบแต่ละรายการแยกตามสาขา และดาวน์โหลด Excel (แผ่นงาน “รวมตามผู้จำหน่าย” และ “ต่อสาขา”) เพื่อใช้ออก PO และส่งให้ผู้จำหน่าย · สรุปและไฟล์ใช้สถานะที่เลือกไว้ด้านบน (รอดำเนินการ / ดำเนินการแล้ว / สาขารับแล้ว / ทั้งหมด) ชื่อไฟล์ระบุสถานะและช่วงวันที่ · ติ๊ก “แยก sheet ตามผู้จำหน่าย” เพื่อให้ผู้จำหน่ายแต่ละรายมีแผ่นงานของตนเอง

เวลาเป้าหมาย (SLA)

สาขาส่งใบสั่งซื้อSales Support ดำเนินการภายใน
ก่อน 10:00 ของวันสั่ง14:00 ของวันเดียวกัน
หลัง 10:00โดยเร็วที่สุด (ระบบแสดงป้าย “ส่งหลัง 10:00” ในรายงานของ Ops)

การกำหนดรอบสั่ง (ฝ่ายขาย)

  • ชิป ตั้งค่า → รอบสั่งของสาขา (หน้าแสดงเฉพาะสาขานำร่องก่อน ติ๊กออกเพื่อดูทุกสาขา · ปุ่มบันทึกเขียนเฉพาะแถวที่แก้ไข): กำหนดรายสาขา ได้แก่ รอบ 1 (อังคาร/พุธ) · รอบ 2 (ศุกร์/เสาร์) · วันสั่งแซลมอน · วันส่ง การกำหนดมีผลตั้งแต่รอบถัดไป
  • หากยังไม่กำหนด ระบบจะใช้ค่าเริ่มต้น (อังคาร / ศุกร์ / แซลมอนวันจันทร์) และแสดงคำเตือนที่หน้าสาขา

ข้อมูลที่ Ops ใช้ติดตาม

  • ชิป ใบสั่งซื้อ → ตรวจสอบการสั่ง แสดงมูลค่ายอดแนะนำ · ยอดที่สาขายืนยัน · ยอดที่ส่วนกลางดำเนินการ · ยอดรับจริง ต่อรอบ เพื่อระบุว่าผลต่างเกิดที่สาขา ส่วนกลาง หรือการจัดส่ง
  • ชิป ปิดงวดเดือน → สรุปผลต่างรายเดือน และ Management Report รายเดือน ข้อ 13A

งานสิ้นเดือน: ปิดงวดเดือน

ชิป ปิดงวดเดือน → สินค้าส่วนกลางและนำเข้าข้อมูล เลือกเดือนที่ปิดงวด หน้าจอแสดงขั้นตอนที่ 1–6 พร้อมสถานะ (เสร็จแล้ว / รอดำเนินการ / ติด) และผู้รับผิดชอบ · หน้างานแสดงขั้นตอนที่ยังค้างเป็นรายการงาน
ขั้นตอนผู้ทำวิธีทำ
1 สูตรเวอร์ชันที่มีผลในเดือนนี้ฝ่ายวิเคราะห์ตรวจสอบและปล่อยที่ สูตรและการปล่อย → ตรวจและปล่อยเวอร์ชัน (ผู้บริหารรับทราบที่หน้างาน)
2 นำเข้ารายงานส่วนกลางประจำเดือนSales Supportไฟล์รายงานยอดสั่งสินค้าของเดือน ไฟล์เดียว: ติ๊กสาขาที่จะบันทึกใบรับสินค้า → ดูตัวอย่าง (บัญชีสินค้าและใบรับของแต่ละสาขา) → บันทึก ระบบบันทึกบัญชีสินค้าและใบรับพร้อมกัน สาขาที่บันทึกรับสินค้าเองแล้วจะไม่ถูกบันทึกซ้ำ
3 จับคู่รหัสวัตถุดิบในสูตรกับรหัสสินค้าส่วนกลางฝ่ายวิเคราะห์ / Sales Supportยอมรับข้อเสนอที่ชื่อและหน่วยตรงกัน รายการที่ไม่แน่ใจให้สอบถามครัว
4 ผลตรวจนับต้นงวดและปลายงวดจากแบบฟอร์มSales Support แทนสาขาระบบเลือกสาขาและวันที่ที่ยังขาดให้ → ดาวน์โหลดแบบฟอร์มตรวจนับ → สาขากรอก → นำเข้า (ต้นงวดก่อนปลายงวด)
5 ยืนยันรับสินค้าครบและระบุเหตุผลผลต่างสาขากด “ไปที่ขั้นตอน →” เปิด สาขาของฉัน → ผลต่างการใช้ ของสาขานั้น
6 สรุปผลต่างรายเดือนOps / ผู้บริหารปิดงวดเดือน → สรุปผลต่างรายเดือน
ปลดล็อกการบันทึก: ดูข้อมูลและดูตัวอย่างก่อนบันทึกได้ทุกหน้าโดยไม่ต้องใช้ token · การบันทึกจริงต้องกดชิป “ยังไม่ปลดล็อกการบันทึก” ที่มุมขวาของแถบด้านบนและกรอก Owner Write-Token ครั้งเดียวต่อเบราว์เซอร์ (ขอได้จากเจ้าของระบบ) หลังจากนั้นชิปแสดง “ปลดล็อกการบันทึกแล้ว”

การอบรม 1 ชั่วโมง (Sales Support)

นาทีหัวข้อ
0–10ภาพรวมขั้นตอน: สาขาตรวจนับ → ระบบแนะนำยอดสั่ง → สาขายืนยันและส่ง → ส่วนกลางดำเนินการ → สาขารับสินค้า → ผลต่างการใช้
10–25ฝึกปฏิบัติในคิว: เปิดใบสั่งซื้อตัวอย่าง แก้ไขยอดพร้อมเหตุผล ระบุเลขที่ PO และกดดำเนินการแล้ว
25–35สรุปรวมตามผู้จำหน่ายและไฟล์ Excel (ตามสถานะ · แยก sheet ตามผู้จำหน่าย) เปรียบเทียบกับรูปแบบใบสั่งซื้อที่ใช้อยู่ในปัจจุบัน
35–45ตารางรอบสั่งของสาขานำร่อง 4 สาขา ที่ ตั้งค่า → รอบสั่งของสาขา (ฝ่ายขายกรอกข้อมูลจริง) · ปิดงวดเดือน: นำเข้ารายงานส่วนกลางและผลตรวจนับ
45–60กรณีพิเศษ: สาขาไม่ตรวจนับ (ไม่หักยอดคงเหลือ) · สินค้าขาด · ส่งล่าช้า · ถาม-ตอบ
