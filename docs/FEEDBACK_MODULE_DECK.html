📱 แบบสอบถาม QR หน้าร้าน

รีวิวสาธารณะมาไม่กี่ครั้งต่อเดือน แต่ QR บนโต๊ะถามได้ทุกโต๊ะทุกวัน ใช้เวลาแขก 20 วินาที ไม่ต้องขอสิทธิ์จากแพลตฟอร์มไหนเลย เพราะเป็นช่องทางของร้านเอง

1

ให้คะแนน 1–5 + หัวข้อที่พูดถึง + ข้อความสั้น + เบอร์/LINE ถ้าอยากให้ติดต่อกลับ — เก็บเบอร์ไว้เท่าที่จำเป็นแล้วลบทิ้งอัตโนมัติ

2

คำตอบลบพร้อมเบอร์ = ขึ้นกล่องงานทันที ให้สาขาโทรกลับได้ก่อนที่แขกจะเดินออกจากร้าน

3

ให้ 4–5 ดาวจะเห็นปุ่มชวนไปรีวิว Google ดันคนที่ประทับใจไปเขียนรีวิวสาธารณะ แทนที่จะปล่อยให้เงียบหาย

4

QR วาดจากเซิร์ฟเวอร์ ไม่ใช่จากอินเทอร์เน็ตร้าน การ์ดที่พิมพ์แล้วใช้ได้เสมอ ต่อให้เน็ตร้านหลุดตอนพิมพ์ก็ยังสแกนติด

วิเคราะห์อัตโนมัติ

ทุกข้อความถูกอ่านให้ ไม่ใช่แค่เก็บไว้เฉยๆ

สองเอนจิน ผลลัพธ์รูปแบบเดียวกัน แต่ละแถวบันทึกว่าเอนจินไหนวิเคราะห์ เพื่อให้อ่านผลด้วยความมั่นใจที่เหมาะสม

🧠 Claude (เมื่อตั้งค่า API key)

  • อ่านบริบทได้ลึกกว่าคำต่อคำ เข้าใจประชด กันเอง แซว
  • สรุปเรื่องราวรายสัปดาห์ + ตอบคำถามที่พิมพ์เป็นภาษาคน
  • ร่างคำตอบรีวิวให้ ทีมแก้แล้วส่งได้เลย

📖 เล็กซิคอนไทย (ใช้ได้เสมอ สำรอง)

  • จับคำในกลุ่มหัวข้อ + หน้าต่างคำปฏิเสธ ("ไม่อร่อย" ไม่ใช่ "อร่อย")
  • ดาวเป็นตัวช่วยตัดสินเมื่อข้อความกำกวม
  • ทำงานได้ทันทีแม้ไม่มี API key — ไม่มีวันหยุดวิเคราะห์
