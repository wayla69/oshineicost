Oshinei Dashboard · โมดูล 💬 เสียงลูกค้า

Checklist เปิดใช้งานเสียงลูกค้าให้ครบทุกช่องทาง

คู่มือแบบจับมือทำ ทีละคลิก: ตั้งค่าแต่ละแพลตฟอร์ม ทดสอบ วางกระบวนการประจำ และตรวจรับ พิมพ์ฉบับนี้ไว้ทำงานคู่กับหน้า interactive (สถานะติ๊กร่วมกันทั้งทีม) — ทุกขั้นตอนบอกว่าทำอย่างไร ทำไม สำเร็จเมื่อไร และถ้าติดทำอย่างไร

วิธีใช้เอกสารนี้

  • ทำตามลำดับเฟส 0 ก่อน จากนั้นเฟส 1, 2, 4, 6 ทำคู่ขนานได้ในสัปดาห์แรก เฟส 1 และ 3 มีช่วงรออนุมัติ ยื่นให้เร็วแล้วไปทำเฟสอื่น
  • ทุกงานมีช่องสถานะ 4 ช่องและบรรทัดหมายเหตุ ติ๊กและจดบนกระดาษ แล้วไปติ๊กในหน้า interactive เพื่อให้ทีมเห็นสด
  • คำสั่งทั้งหมดพิมพ์ในหน้าต่าง Command Prompt ที่โฟลเดอร์ C:\Users\ASUS\Oshinei บนเครื่อง sync
  • ไฟล์ตั้งค่า backend\.feedback_config.json และ backend\.env เป็นความลับ แก้บนเครื่องนั้นเท่านั้น ห้ามส่งทางแชท

สัญลักษณ์และสีที่ใช้

  • สีเหลือง = คำสั่ง ชื่อไฟล์ ลิงก์ ที่ต้องพิมพ์หรือเปิดให้ตรงทุกตัวอักษร
  • ฟ้า = ทำไมต้องทำ   เขียว = รู้ว่าสำเร็จเมื่อ   ชมพู = ถ้าติดให้ทำอย่างนี้
  • พีช = ข้อควรระวัง ห้าม หรือจุดที่พลาดแล้วเสียเวลามาก   ม่วง = ค่า/ตัวเลขที่ต้องจด
  • ช่อง ☐ ข้างขั้นตอน = ติ๊กเมื่อทำเสร็จ · แถบลายในไทม์ไลน์ = รอฝ่ายภายนอกอนุมัติ
