# คำที่ใช้กับพนักงานสาขา (PR-PW · มติเจ้าของ 22 ต.ค. 2026)

เกณฑ์: คำที่คนหน้าร้านใช้พูดกันทุกวัน สั้น สุภาพ ไม่ใช้ภาษาอังกฤษถ้ามีคำไทย **หนึ่งเรื่องใช้คำเดียว** ทุกหน้าจอ ทุกข้อความ คู่มือ บัตรงาน เอกสารแจกและเอกสารขั้นตอน
ใช้เฉพาะข้อความที่สาขาอ่าน หน้าของฝ่ายกลาง (ประสานงานขาย คลัง ฝ่ายวิเคราะห์ บัญชี ผู้บริหาร) ใช้คำทางการเดิม ยกเว้นเมื่อแสดงป้ายเดียวกับที่สาขาเห็น (ใช้ป้ายเดียวต่อหนึ่งเรื่อง)
คำเดิมยังค้นหาเจอ: อยู่ในคำค้นหาของเมนู (`PAGE_KEYWORDS` ใน `js/01-core.js`)

## ตารางคำ

| คำเดิม (ภาษาสำนักงาน) | คำของสาขา | ใช้ที่ไหน |
|---|---|---|
| ตรวจนับ / ตรวจนับสิ้นเดือน | นับของ / **นับของสิ้นเดือน** | ชื่อหน้า ปุ่ม ข้อความ แถบล่าง หน้างาน เมนู คู่มือ บัตรงาน |
| ผลตรวจนับ / ใบตรวจนับ | ผลนับ / ใบนับของ | หน้านับของ ประวัติ ข้อความตอบกลับ |
| ต้นงวด | นับครั้งแรก (ในหัวตาราง: ต้นเดือน) | หน้านับของ ประวัติการนับ ขั้นปิดเดือน ไฟล์ Excel |
| ปลายงวด | นับสิ้นเดือน (ในหัวตาราง: สิ้นเดือน) | เหมือนกัน |
| ปิดงวด / งวด | ปิดเดือน / เดือน | ข้อความเตือน หน้าส่วนต่าง ป้ายสถานะ |
| ตรวจนับหมุนเวียน | นับเสริมรายสัปดาห์ | สวิตช์บนหน้านับของ ข้อความอธิบาย |
| สั่งสินค้า | **สั่งของ** | ชื่อหน้า ปุ่มแถบล่าง หน้างาน เมนู |
| รับสินค้า / ใบรับสินค้า | **รับของ** / ใบรับของ | ชื่อหน้า ปุ่ม ประวัติ ข้อความ ชื่อไฟล์ Excel |
| ยอดแนะนำ | จำนวนที่ควรสั่ง | หน้าสั่งของ ปุ่ม “สั่งตามจำนวนที่ควรสั่งทั้งหมด” ไฟล์ Excel |
| คงเหลือตามระบบ (ของในระบบ) | **ของที่ควรเหลือ (ตามระบบ)** · ในประโยคเขียน “ของที่ควรเหลือ” · ป้ายแถวที่แคบเขียน “ควรเหลือ” (กฎเดียว: คำเต็มเป็นป้ายและหัวตาราง คำสั้นเฉพาะที่แคบ) | ใบตัดเบิก สั่งของ ส่วนต่าง ไฟล์ Excel |
| ร่าง / บันทึกร่าง / ล้างร่าง | ยังไม่ส่ง / บันทึกไว้ก่อน / ลบที่กรอกไว้ | ป้ายสถานะ ตัวกรอง ข้อความ ปุ่มของใบตัดเบิก ใบสั่งซื้อ ผลนับ |
| กลุ่มมูลค่าสูง / กลาง / ต่ำ (A / B / C) | ของแพง / ของราคาปานกลาง / ของราคาถูก (ในช่องแคบ: แพง / ปานกลาง / ถูก) | ป้ายรายการ คำถามเหตุผล หัวตาราง Excel |
| ใช้วันส่งค่าเริ่มต้น | ยังไม่ได้ตั้งวันส่งของสาขา | หน้าสั่งของ |
| จำนวนที่ควรสั่งจากใบตัดเบิก N วัน (ส่งแล้ว x/y วัน) | คิดจากใบตัดเบิก N วัน (x/y อยู่หลังปุ่ม “?”) | หน้าสั่งของ |
| รายการหน้างานยาว (ปิดเดือน …) | ชื่อสั้นหนึ่งประโยค รายละเอียดเป็นจำนวนที่เหลือ (ไม่เกินราว 50 ตัวอักษร) | หน้างาน |
| ปกติของสาขา | ที่สาขาใช้ปกติ | ส่วนต่างรายวัน ใบตัดเบิก ไฟล์ Excel |
| ค่ากลางทุกสาขา | เฉลี่ยทุกสาขา | ส่วนต่างรายวัน ไฟล์ Excel |
| เวลาตัดรอบ / วันตัดรอบ | เวลาส่งสุดท้าย (ในรายการใบสั่งซื้อ: “ส่งก่อน …”) | หน้าสั่งของ หน้างาน การแจ้งเตือน ข้อความเตือน |
| รอบส่ง | รอบส่งของ | หน้าสั่งของ ข้อความยืนยัน การแจ้งเตือน |
| ส่งล่าช้า / ล่าช้า (ค่าปรับ) | ส่งช้า (มีค่าปรับ) | ป้ายใบสั่งซื้อ ใบตัดเบิก คำเตือน |
| ยืนยัน (ใบตัดเบิก ใบสั่งซื้อ ผลนับ) | **ส่ง** | ปุ่ม ป้ายสถานะ ข้อความ: “ส่งใบตัดเบิก” “ส่งแล้ว” “ส่งช้า” |
| ยืนยันรับสินค้าครบ | แจ้งว่าบันทึกรับของครบ | หน้าส่วนต่าง ขั้นปิดเดือน |
| คลังยืนยันยอดส่ง | คลังบันทึกจำนวนที่ส่ง | ข้อความบนหน้าสั่งของ (หน้าของคลังเองยังเรียก “ยืนยันยอดส่ง”) |
| ผลต่าง (ผลต่างการใช้ / ผลต่างของฉัน) | **ส่วนต่าง** (ส่วนต่างการใช้) | ชื่อหน้า แท็บ ปุ่ม ชื่อไฟล์ Excel |
| ส่วนต่าง (ตอนรับของไม่ครบ) | ที่ขาด / สาเหตุที่ขาด | ฟอร์มรับของ (เปลี่ยนเพื่อไม่ให้คำเดียวมีสองความหมาย) |
| กระทบยอด | เทียบของ | แท็บสิ้นเดือน ชื่อไฟล์ Excel |
| เกณฑ์ / เกินเกณฑ์ | ต่างมาก / เกินกำหนด / ช่วงที่ยอมรับ | คำถามเหตุผลของส่วนต่าง ป้ายเตือน |
| เคลม / แจ้งเคลม / แจ้งเคลมส่วนต่าง | **แจ้งของขาด/เสีย** (เรื่องที่แจ้ง) | การ์ดและปุ่มบนหน้ารับของ ข้อความ คู่มือ |
| หน่วยฐาน | หน่วยเล็กสุด | ป้ายและข้อความเตือนที่สาขาเห็น |
| ขนาดบรรจุ | ขนาดแพ็ค | ปุ่ม “ขนาดแพ็คไม่ตรง” ป้าย “ยังไม่มีขนาดแพ็ค” |
| ประมาณการ | ประมาณ | ป้าย “ประมาณจากยอดขาย N วัน” |
| รายการที่ต้องสั่ง | ของที่ต้องสั่ง | ตัวกรองหน้าสั่งของ |
| ส่วนกลาง (เป็นชื่อทีม) | สำนักงานใหญ่ | ไม่มีข้อความของสาขาที่ใช้คำนี้แล้ว (ตรวจโดย `test_bom_center_language.py`) |
| ดำเนินการ | ทำ / จัดการ | ไม่มีข้อความของสาขาที่ใช้คำนี้แล้ว |

## คำที่ยังเก็บไว้ (พนักงานใช้อยู่แล้ว หรือชัดอยู่แล้ว)

| คำ | เหตุผล |
|---|---|
| ตัดเบิก / ใบตัดเบิก | คำที่พนักงานใช้ทุกวันอยู่แล้ว |
| ใบสั่งซื้อ | ชัดกว่า “ใบสั่ง” และตรงกับเอกสารจากคลัง |
| เบิกใช้ / ของเสีย / รับจริง / ส่งจริง | ตรงกับป้ายหน้าจอที่ใช้อยู่ |
| โซน (เจ้าของให้คงไว้) / ต้องนับ | ยังไม่อยู่ในรายการที่เจ้าของให้ทบทวน |
| ประสานงานขาย / คลัง / ฝ่ายวิเคราะห์ | ชื่อแผนก |

## ภาษาที่ห้ามใช้บนหน้าสาขา (คงเดิม)

“กรุณา” · “ระบบจะ” · “ฉบับร่าง” · ประโยคอธิบายยาวบนหน้า (ใส่หลังปุ่ม “?”) · รายการที่เสร็จแล้วซ่อนไว้เป็นค่าเริ่มต้น
