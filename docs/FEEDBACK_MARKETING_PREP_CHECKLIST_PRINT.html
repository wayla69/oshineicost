Oshinei Dashboard · โมดูล 💬 เสียงลูกค้า

Checklist การตลาด: ไปขอข้อมูล/สิทธิ์จากแต่ละแพลตฟอร์ม ส่งให้ทีมระบบ

คู่มือของฝั่งการตลาด สำหรับ 'โมดูลเสียงลูกค้า' — ก่อนทีมระบบจะเชื่อมต่อแต่ละแพลตฟอร์มได้ ต้องมีคนที่ถือบัญชี Google/Facebook/Instagram/TikTok ของร้านไปขอสิทธิ์ กรอกฟอร์ม และส่งค่าที่ได้กลับมาให้ก่อน — เอกสารนี้บอกทีละแพลตฟอร์มว่าต้องไปขออะไร ทำไม และรู้ได้อย่างไรว่าทำสำเร็จแล้ว คู่กับ Checklist เปิดใช้งานระบบ (ฝั่งเทคนิค) ที่ทีมระบบใช้ทำต่อ

วิธีใช้เอกสารนี้

  • ทำเฟส 0 ก่อนเสมอ (ตัดสินใจ + เตรียมข้อมูลบริษัท) — ใช้ซ้ำในทุกฟอร์มที่ตามมา
  • เฟส 1 (Google) และเฟส 3 (TikTok) ต้องยื่นให้เร็วที่สุดตั้งแต่วันแรก เพราะรออนุมัติเป็นสัปดาห์ — เฟสอื่นทำคู่ขนานระหว่างรอได้
  • ทุกขั้นตอนบอกว่า "ส่งอะไรให้ทีมระบบ" ชัดเจน — ส่งค่าที่ได้ผ่านช่องทางที่ปลอดภัยเท่านั้น ไม่ใช่แชทกลุ่มเปิด
  • ปิดท้ายด้วยเฟส 7 ที่สรุปว่าอะไรไม่ใช่หน้าที่การตลาด (Claude API key, Fly secrets) กันทำงานซ้ำซ้อนกับทีมระบบ

สัญลักษณ์และสีที่ใช้

  • สีเหลือง = คำสั่ง ชื่อไฟล์ ลิงก์ ที่ต้องพิมพ์หรือเปิดให้ตรงทุกตัวอักษร
  • ฟ้า = ทำไมต้องทำ   เขียว = รู้ว่าสำเร็จเมื่อ   ชมพู = ถ้าติดให้ทำอย่างนี้
  • พีช = ข้อควรระวัง ห้าม หรือจุดที่พลาดแล้วเสียเวลามาก   ม่วง = ค่า/ตัวเลขที่ต้องจด
  • ช่อง ☐ ข้างขั้นตอน = ติ๊กเมื่อทำเสร็จ · แถบลายในไทม์ไลน์ = รอฝ่ายภายนอกอนุมัติ
