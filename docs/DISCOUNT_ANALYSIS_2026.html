Executive Summary — การใช้ส่วนลดผิดปกติ ครึ่งปีแรก 2569
ข้อค้นพบวิกฤต: ระบบ POS ของ Oshinei Enterprise บันทึกส่วนลดมูลค่า ฿7,480,820 จากบิลทั้งหมด 4,397 บิล ในช่วง H1 2569 โดย 99% ของบิลไม่มีการระบุเหตุผลการลดราคา และพบพฤติกรรมผิดปกติสูงกระจุกตัวอยู่ที่ สาขาอุดรธานี ซึ่งมีสัดส่วนส่วนลดต่อยอดขายสูงถึง 3.98% — สูงกว่าค่าเฉลี่ยเครือ 3 เท่า
ประเด็นสำคัญที่พบ
1. การกระจุกตัวของผู้ใช้งาน
ผู้ใช้งาน "admin" สาขาอุดรธานี รับผิดชอบบิลส่วนลด 1,287 บิล (78%) มูลค่า ฿2,437,480 ซึ่งไม่สอดคล้องกับหน้าที่ตามปกติของ account ระดับผู้ดูแลระบบ
2. ค่าส่วนลดคงที่ซ้ำผิดปกติ
พบส่วนลดจำนวน ฿631 ซ้ำ 456 ครั้ง ซึ่งเป็นค่าที่ไม่ใช่ราคาโปรโมชันมาตรฐาน สื่อถึงการตั้งค่าอัตโนมัติหรือการกระทำตั้งใจ
3. พฤติกรรมรายเดือนมิถุนายน
เดือนมิถุนายน (MTD) อุดรธานี มีค่าเฉลี่ยส่วนลดต่อบิลพุ่งขึ้นเป็น ฿2,961 จาก ฿1,658 ในเดือนเมษายน — เพิ่มขึ้น 78.6% ใน 2 เดือน
4. ช่วงเวลาเย็น–ดึกมีความเสี่ยงสูง
บิลส่วนลด 70.5% เกิดขึ้นในช่วง 18:00–22:00 น. ซึ่งเป็นช่วงที่ผู้จัดการส่วนมากออกจากสาขาแล้ว
5. ธุรกรรมเงินสดครองส่วนใหญ่
67% ของบิลส่วนลดสาขาอุดรธานีชำระด้วยเงินสด ซึ่งตรวจสอบย้อนหลังได้ยากและมีความเสี่ยงต่อการทุจริตสูงกว่าช่องทางอิเล็กทรอนิกส์
6. ส่วนลด 100% (ฟรีทั้งบิล)
พบบิลที่ลดราคา 100% จำนวน 49 บิล มูลค่า ฿93,780 ที่สาขาอุดรธานี โดยไม่มีการบันทึกเหตุผลแม้แต่บิลเดียว

REC-03: บล็อก Default ส่วนลด ฿631
ให้ฝ่าย IT ค้นหาและลบ/ปิดการใช้งาน preset discount ฿631 ออกจากระบบ POS สาขาอุดรธานีทันที พร้อมตรวจสอบว่ามีที่สาขาอื่นด้วยหรือไม่
REC-04: กำหนด Mandatory Reason Code
อัพเดทระบบ POS ให้บังคับระบุเหตุผลส่วนลดก่อนบันทึกทุกกรณี โดยระบบต้องไม่อนุญาตให้ปิดบิลที่มีส่วนลดโดยไม่เลือก reason code จากรายการที่กำหนด
มาตรการระยะสั้น (ภายใน 2 สัปดาห์)
REC-05: Approval Workflow
ส่วนลด >20% หรือ >฿500 ต้องผ่านการอนุมัติจาก supervisor ผ่านระบบ (2-factor: PIN ผู้บันทึก + PIN supervisor) ก่อนบันทึก
REC-06: Real-time Alert
ตั้ง alert ส่ง LINE/SMS ถึงผู้จัดการเขตทันทีเมื่อบิลส่วนลดเกิน ฿1,500 หรือเมื่อรายวันสะสมเกิน ฿10,000
REC-07: Admin Account Audit
ตรวจสอบทุก admin account ทั้ง 27 สาขา ว่ามีการใช้บันทึกธุรกรรมขายหรือไม่ ถ้ามี ให้ถอดสิทธิ์ส่วนลดออกจาก admin accounts ทั้งหมด
มาตรการระยะยาว (ภายใน 1–3 เดือน)
REC-08: Discount Policy
จัดทำนโยบายส่วนลดฉบับใหม่ กำหนดประเภท, วงเงิน, ผู้มีอำนาจอนุมัติ, เอกสารประกอบ และบทลงโทษ
REC-09: Monthly Dashboard
จัดทำ Discount Dashboard รายเดือนส่งผู้บริหารทุกสาขาพร้อมเปรียบเทียบกับ benchmark และ alert สาขาที่เกิน threshold
REC-10: Cash Policy Reform
กำหนดให้บิลเงินสดที่มีส่วนลดเกิน ฿500 ต้องมีลายมือชื่อลูกค้าและผู้จัดการ เก็บ physical record
ผลที่คาดว่าจะได้รับ: หากดำเนินการตาม REC-01 ถึง REC-07 ครบถ้วน คาดว่าจะสามารถลดมูลค่าส่วนลดที่ผิดปกติลงได้อย่างน้อย 60–70% ภายในเดือนแรก และสามารถนำ evidence ที่ได้จาก REC-02 ไปดำเนินการทางกฎหมายหรือทางวินัยกับบุคคลที่เกี่ยวข้องต่อไป
