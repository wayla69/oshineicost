ยอดซื้อวัตถุดิบ เทียบ ยอดขาย รายสาขา (รายสัปดาห์)

ยอดซื้อวัตถุดิบ นำเข้าจากระบบจัดซื้อเป็นไฟล์ Excel (สาขา + สัปดาห์ + ยอดรวม) · ยอดขาย เป็นตัวเลขของระบบนี้เอง → ได้ % ยอดซื้อต่อยอดขาย ของแต่ละสาขา
⚠ คนละตัวกับ Food cost (BoM) — BoM คือ “ตามสูตรควรใช้เท่าไร”, หน้านี้คือ “ซื้อเข้าจริงเท่าไร” การซื้อมาก่อนขาย (ตุนของ/รอบส่งของ) ทำให้รายสัปดาห์แกว่งได้มาก จึงควรอ่านคู่กับค่าเฉลี่ยรวมช่วง

→

แนวโน้มรายสัปดาห์ — % ยอดซื้อวัตถุดิบต่อยอดขาย

คลิกปุ่มมุมกราฟเพื่อเจาะลึก + อ่านสรุป · จุดใหญ่สีแดง = สัปดาห์ที่หลุดกรอบของสาขานั้น

ยอดซื้อ เทียบ ยอดขาย (รวมทุกสาขาในช่วง)

แท่ง = ยอดขาย · เส้น = ยอดซื้อวัตถุดิบที่นำเข้า — ช่องว่างคือสัปดาห์ที่ยังไม่ได้นำเข้าไฟล์

สรุปรายสาขา (ทั้งช่วง)

คลิกหัวคอลัมน์เพื่อเรียง · ⚠ = % หลุดกรอบเทียบสาขาอื่น · สัปดาห์ที่ยังไม่นำเข้าไม่ถูกนับเป็น 0 แต่จะนับเป็น “ขาดไฟล์”

สาขายอดซื้อวัตถุดิบ ยอดขาย (ex-VAT)% ต่อยอดขาย ซื้อ/หัวลูกค้าสัปดาห์ ขาดไฟล์

รายสัปดาห์ × สาขา

คลิกหัวคอลัมน์เพื่อเรียง · แก้ตัวเลขในช่อง “ยอดซื้อ” ได้โดยตรงแล้วกด Enter (ใช้เมื่อต้องแก้ทีละรายการ — ทั้งชุดให้ใช้ไฟล์ Excel)
